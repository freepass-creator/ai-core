# 제안 보류 — 직원 한 줄 요청 접수

이 문서는 미래 개선안이다. **현재 운영 규칙이나 자동화 명령이 아니다.** 2026-08-20 Claude 구조 검토로 다음 항목은 별도 설계와 승인이 끝날 때까지 보류한다.

- 업무내비게이션에 새 「요청」 탭을 만드는 일
- Codex의 주기적 폴링, 직원 입력의 자동 분류·자동 실행
- Gemini의 직접 Sheet/Drive 접근 또는 Codex 실행 트리거
- Sheet에 처리 결과를 자동으로 쓰는 일

직원은 현재 Codex 또는 Gemini에 질문·보고할 수 있다. Gemini는 안내와 비식별 요약만 하고, Codex는 필요한 경우 비식별 `DRAFT`를 만든다. 어떤 직원 입력도 라이브 실행 명령이 아니다.

## 나중에 구현하려면

1. Claude가 새 요청 접수 흐름·신원/역할 범위·보존 기간·오류 처리·권한을 C등급 구조로 설계한다.
2. Codex가 비라이브 프로토타입과 DRY RUN을 만들어 검증한다.
3. 실제 Sheet/Drive/데이터센터 쓰기 기능은 각각 D등급으로 Claude DESIGN·FINAL과 대표의 직전 실행 승인을 받는다.
4. 한정된 사용자·리소스에서 검증한 뒤에만 범위를 넓힌다.

자동화 목표 자체는 유지한다. 다만 현재 우선순위는 직원 한 줄을 즉시 실행하는 것이 아니라, **안전한 접수·검토·승인 경로를 먼저 만드는 것**이다.
