## 4. ★어떻게 넘기나 — 한 자리에서 «바로» 부른다

> 대표(2026-09-02): 「**4개 ai 맞대고 어떻게 하면 통합되어서 잘 돌아갈수 있을까**」

★**자리는 `scripts/협업.mjs` 하나다.** 쪽지만 남기면 그건 협업이 아니라 «중계» 다.

```bash
node scripts/협업.mjs                       # 지금 넷이 무엇을 쥐고 있나
node scripts/협업.mjs 검수한다 <파일…> --왜="…" --관점=로직|자료|보안   # ★셋에게 동시에 — 개인정보만 지워 보낸다
node scripts/협업.mjs 물어본다 --무엇="…"                              # 셋에게 동시에
node scripts/협업.mjs 시킨다 --받는이=코덱스 --무엇="…"                 # 한 사람에게
node scripts/협업.mjs 판정한다 --번호=H-… --참=4 --거짓=2 --무엇="…"   # ★검증한 결과를 남긴다
node scripts/협업.mjs 성적                                             # ★누가 무엇을 잘 맞히나
```

★**기본은 읽기 전용이다** — 코덱스 `-s read-only` · 제미나이 `--approval-mode plan` · 커서 `--mode ask`.
  정말 고치게 하려면 `--쓰기` 를 준다.
★**개인정보만 지운다.** 대표(2026-09-01): 「어차피 **법인자료니까 개인정보 빼고는 전혀 상관없어**」 —
  차량번호·법인명·금액·VIN 은 «지우지 않는다». 지우면 검수가 안 된다.
  지우는 것은 주민번호·전화·계좌·이메일과 «아는 고객 이름» 뿐이고, **무엇을 몇 건 지웠는지 먼저 보여준다.**

### ★★답을 그대로 믿지 않는다 — 이것이 통합의 고갱이다

★**지적은 «아직 참이 아니다».** 실측으로 하나씩 검증하고, **검증한 결과를 반드시 남긴다.**
남기지 않으면 다음 세션이 또 처음부터 잰다.

```
검수한다  →  셋이 지적한다        (몇 분)
          →  ★내가 실측으로 «참인지» 가른다
판정한다  →  참 N · 거짓 N 을 적는다
성적      →  쌓이면 «누구에게 무엇을 물을지» 가 근거로 정해진다
```

**첫 실측 (2026-09-02 · `asset-registration-population.mjs` · 관점 「자료」)**

| | 지적 | 참 | |
|---|---:|---:|---|
| 커서 | 6 | **4** | ★가장 날카로웠다 — 「소재=등록증만」인데 **등록증 0장이 46대**. 이름이 거짓말이었다 |
| 코덱스 | 3 | 2 | 정본을 백업 없이 덮어씀 · 소유를 「모른다」로 두지 않고 단정 |
| 제미나이 | 1 | 1 | 우리 법인번호가 아니라고 「우리법인아님」으로 단정 — 오타·신규법인일 수 있다 |

★**셋이 겹치지 않는 것을 잡았다.** 커서가 이름의 거짓말을, 코덱스가 덮어쓰기를, 제미나이가 단정을 봤다.
★**성적이 낮다고 빼지 않는다.** 만든 사람이 검증하면 놓친다 — 둘째 눈은 성적과 상관없이 필요하다.
★**검수는 「쓰기가 있는 작업」에 붙인다.** 읽고 세는 것은 실측이 더 빠르고 정확하다.

### 못 돌리는 상대에게는 남겨만 둔다

```
클로드  →  docs/INBOX.md 에 요청을 «쓴다»
           큰 건이면 docs/교차검증요청-….md 로 따로 (무엇을 물을지 번호를 매겨서)
코덱스  →  같은 자리에 «회신» — 승인 / 보완 / 차단 · 이유 · 다음 조건
클로드  →  반영하고 docs/클로드회신-….md 로 답한다
```

★**대표는 클로드에게 한 번만 말한다.** AI 를 부르는 것은 클로드가 한다.
★제미나이·커서는 «그 자리에서» 부른다 — 답이 바로 온다.

### ★부탁하는 말 (그대로 쓴다)

```
★고치지 말고 «맞나 틀리나» 만 봐 달라. 고칠 것은 협의해서 정한다.
★읽기 전용으로. Drive·Firestore·Sheet 를 바꾸지 말라.
★판정은 «승인 / 보완 / 차단 · 이유 · 다음 조건» 으로 짧게.
★개인정보(주민번호·연락처·주소)는 넘기지 않는다. 상태와 수만 넘긴다.
```

★**「차단(BLOCK)」 이 오면 «낸다».** 2026-09-02 에 그 판정이 맞았다.

## 5. ★혼자 «확인했습니다» 하지 않는다

★**「됐습니다」 는 «문턱을 지났다» 는 뜻일 때만** 쓴다. 눈으로 훑은 것은 «확인» 이 아니다.

```bash
node wonja/gwataeryo-naegi-jeon-jeomgeom.mjs     # 과태료 — 열 가지 문턱
node --test "test/*.test.mjs"                     # 시험
node wonja/maribdoena-geomsa.mjs                  # 지금 자료에 옛 실수가 남아 있나
```

★**남이 잡아 준 것은 «문턱으로» 만든다.** 말로만 고치면 다음에 또 난다 —
  코덱스가 잡은 둘은 지금 `test/gwataeryo-hold-saeji-anneunda.test.mjs` 와
  `test/gwataeryo-deopji-anneunda.test.mjs` 가 매번 잰다.

★**세션을 끝낼 때 틀린 것을 적는다** — `node wonja/silsu-jangbu.mjs --적는다`
