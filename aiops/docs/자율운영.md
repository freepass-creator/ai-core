# ★★자율운영 — 대표가 빠져도 도는 법

대표(2026-08-31): 「**내가 빠질 테니까 너하고 코덱스가 둘이 판단해서**」
「대신에 **하고자 하는 건 내가 정해야** 될 거 아니야. 그 목적지로 가기 위해서」

**이 문서가 「누가 무엇을 정하나」의 정본이다.** [`ROLES.md`](ROLES.md) 는 누가 무슨 «일»을 하나,
여기는 누가 무슨 «판단»을 하나다. 어긋나면 여기가 맞다.

---

## 한 줄로

```
대표    목적지를 정한다            ← 이것만. 그리고 예외함을 본다
AI 둘   거기 가는 길을 다 정한다    ← 판단 · 설계 · 구현 · 검증 · 실행
```

★**「무엇을 할까」는 대표, 「어떻게 할까」는 AI 둘.** 이 선을 넘지 않는다.

---

## ★★둘이 합의하는 법 — 자리가 달라야 견제가 된다

2026-08-29 과태료에서 이미 이렇게 돌렸고, 그대로 전체에 쓴다.

```
        무엇을 하려 한다
              │
     ┌────────┴────────┐
     │                 │
  클로드            코덱스
  ★판을 본다        ★결과물을 연다
  원자 · 판정 근거    실제 PDF · 시트 · 화면
  「셈이 맞나」       「실제로 그렇게 나왔나」
     │                 │
     └────────┬────────┘
              │
     둘 다 ㅇㅋ  →  간다
     하나라도 ✗  →  멈추고 «왜» 를 적는다
     답이 없다   →  ★ㅇㅋ 아님 (침묵은 동의가 아니다)
     둘 다 막힘  →  ★예외함에 쌓고 «다음 것으로 넘어간다» (멈춰 서지 않는다)
```

**같은 것을 둘이 보면 눈이 하나다.** 2026-08-29 에 클로드가 원자만 보고 「주민번호 없다」를 세 번 말했다.
둘 다 원자만 봤으면 둘 다 틀렸을 것이다. **자리를 갈라 둔 것이 유일한 안전장치다.**

### 누가 무엇을 보나

| | 클로드 | 코덱스 |
|---|---|---|
| **본다** | 원자 · 판정 규칙 · 셈 · 지도 | ★실제 결과물 · 라이브 상태 · 배포 |
| **묻는다** | 「이 셈이 맞나」 「근거가 있나」 | 「진짜로 그렇게 나왔나」 「돌려봤나」 |
| **약하다** | 화면·파일을 안 열어 본다 | 왜 그래야 하는지를 안 따진다 |

★**서로의 약한 곳이 상대의 강한 곳이다.** 그래서 둘이다. 하나로 줄이면 견제가 사라진다.

## ★대표에게 올리는 것 — 이 다섯뿐이다

**나머지는 전부 AI 둘이 정한다.** 올릴지 말지 헷갈리면 «올린다» 가 아니라 **이 표에 있나 없나**로 가른다.

| | 무엇 | 왜 AI 가 못 정하나 |
|---|---|---|
| **① 돈의 방향** | 회수 · 해지 · 감면 · 매각 · 계산서 발행 | 손님과의 관계가 걸린다. 성실한 손님이 회수 대상이 되면 안 된다 |
| **② 바깥으로 나가는 것** | 관청 제출 · 문자·메일 발송 · 저장소 공개 | 나가면 되돌릴 수 없다 |
| **③ 사람** | 연락 · 담당 배정 · 고용 | |
| **④ 지울 수 없는 것** | 데이터 삭제 · 권한 변경 · 계정·키 | 되돌릴 수 없다 |
| **⑤ 법·분쟁** | 이의신청 · 내용증명 · 소송 · 개인정보 통지 | |

★**AI 는 「가능 상태」까지 만든다.** ①~⑤ 는 **버튼만 남겨 두고 멈춘다** — 서류는 다 만들어 두고
「내면 된다」 상태로 예외함에 올린다. 대표는 «누를지 말지»만 정한다.

### 반대로 — AI 둘이 «그냥 하는» 것

```
원자 만들기 · 고치기          판정 규칙 세우기 · 바꾸기
시트 읽기 · 쓰기 · 탭 만들기   화면 만들기 · 고치기 · 배포
서류 만들기(내지는 않는다)     도구 · 스크립트 · 매뉴얼
저장소 정리 · 커밋            문제 찾아내기 · 고치기
```

**승인을 기다리지 않는다.** 되돌릴 수 있고 위 다섯이 아니면 **그냥 한다.**

## ★★멈추지 않는 것이 제일 중요하다

대표가 빠지면 **막힌 것이 그대로 서 있는다.** 그게 이 구조를 죽인다.

2026-08-31 아침: 코덱스 작업이 실패했는데 **반나절 아무도 몰랐다.**
2026-08-30 밤: 과태료 22묶음이 합의까지 끝나고 **하루째 안 넘어갔다.**
`INBOX` 판정 대기 **16건**. 작업대장 170건 중 **CANCELLED 45건(26%)**.

### 그래서 셋을 둔다

| | 무엇 | 무엇을 막나 |
|---|---|---|
| **① 지킴이** | `node scripts/지킴이.mjs` — **멈춘 것·실패한 것·어긋난 것만** 뱉는다. 고치지는 않는다 | 아무도 모르는 채로 서 있는 것 |
| **② 예외함** | `docs/예외함.md` — ①~⑤ 에 걸린 것만. **한 줄에 하나, 「누르면 되는 상태」로** | 대표가 무엇을 볼지 몰라 다 보는 것 |
| **③ 막히면 넘어간다** | 한 건이 막혀도 **다음 건을 계속 한다.** 막힌 건 예외함으로 | 하나 때문에 전체가 서는 것 |

★**「멈췄다」를 사람이 알아채는 구조는 사람이 빠지면 무너진다.** 기계가 알아채야 한다.

## 되돌릴 수 있게 — 넷은 지킨다

권한은 다 풀었다(2026-08-30). 대신 **되돌릴 수 있는 것만** 한다.

```
① 쓰기 전에 백업          backups/<날짜>-<무엇>/
② 잠금 안에서            lib/쓴다.mjs — 동시에 두 손이 들어가면 줄이 날아간다
③ 감사기록               .coordination/audit.ndjson — 누가·언제·무엇을·왜
④ 쓴 뒤에 다시 읽는다     「낸 수 = 든 수」 를 견준다. 안 맞으면 되돌린다
```

★**②를 없애지 않는다.** 이건 권한이 아니라 «차례» 다.
2026-08-25 에 인수인계 시트 탭 셋이 그렇게 사라졌다.

## 알아낸 것은 그 자리에 박는다 — 이게 안 되면 다 무너진다

대표가 빠지면 **틀린 것을 잡아 줄 사람이 없다.** 그래서 이것만은 예외 없이 한다.

```
숫자를 알아냈다   →  lib/wonja/*.json · lib/*-jeongbon.json 에 박는다
규칙을 정했다     →  해당 정본 문서를 고친다 (딴 데 새로 쓰지 않는다)
지도가 틀렸다     →  ★그 지도를 고친다
```

2026-08-31 하루에만 낡은 지도 때문에 셋을 틀렸다 —

★**「없다」 가 아니라 「모른다」.** 자료에 구멍이 있으면 지우지 말고 화면 위에 띄운다.

## ★★목적지 — 대표 확정 (2026-08-31)

대표: 「**셋 다 — 순서대로**」

**앞이 서야 뒤가 선다.** 1단계가 안 되면 2·3단계의 결과도 못 믿는다.

```
1단계  ★숫자를 안 틀린다        ← 토대. ★지금 여기
2단계  ★미수 → 손에 잡히는 돈    ← 돈
3단계  ★과태료를 다 턴다        ← 밀린 일
```

---

### 1단계 — 숫자를 안 틀린다 · 「됐다」의 꼴

```
□ 대수 · 미수 · 과태료 · 계약이 «전부» 정본 파일에 있다
    ★지금 미수만 없다. 관리지도는 7,352만, 코덱스 기준은 8,708만 — 둘 다 68건인데 값이 다르다
□ 정본마다 다섯이 박혀 있다   기준일 · 무엇을 세는가 · ★세지 마라(함정) · 다시 뽑는 법 · 값
    본보기: lib/wonja/과태료-정본.json
□ 도구 답이 정본과 갈리면 ★답하기 «전» 에 스스로 걸린다
□ 자료에 구멍이 있으면 「없다」 가 아니라 「모른다」 로 나온다
□ 낡은 지도(CLAUDE.md·docs)가 자동으로 짚인다
```

**재는 법**: `node scripts/숫자.mjs --검사` 가 아무것도 안 뱉으면 1단계 끝.
**왜 이게 먼저인가**: 2026-08-31 하루에만 셋을 틀렸다 — 프라임 145↔44 · 과태료 804↔56 · 「시트 못 씀」.

### 2단계 — 미수 → 손에 잡히는 돈 · 「됐다」의 꼴

```
□ ★통장 구멍부터 메운다        계좌 다섯이 2026-08-20 이후 비어 있다
    → 메우기 «전» 에 독촉하면 «이미 낸 사람» 에게 전화한다. 그건 사고다
□ 34건이 「이미 낸 사람 / 진짜 미수」 로 갈린다
□ 진짜 미수는 전부 «다음 행동 · 기한 · 근거» 를 갖는다
□ 열흘 안에 움직인 흔적이 원장에 남는다
□ 시트 ↔ 원장이 갈리는 줄(고객098 500↔655 등)이 «왜 갈리는지» 까지 적힌다
```

**대표가 누르는 것은 하나** — 「누구부터 회수할까」. 나머지는 AI 둘이 한다.

### 3단계 — 과태료를 다 턴다 · 「됐다」의 꼴

```
□ 미처리 56 → 0
□ 새 고지서가 사람 손 없이 「발송대기」 까지 간다
□ ★워크 화면이 상태를 제대로 센다  (지금은 「전체 − 처리완료」라 넘겨도 미처리로 보인다)
□ 계약없음 46 · 기간오류 14 · 위반일오류 2 가 «원인별» 로 갈려 각자 다음 행동을 갖는다
```

**대표가 누르는 것은 하나** — 「문서24에 낼까」(관청별).

---

★**단계를 건너뛰지 않는다.** 다만 **막히면 서 있지 않는다** — 막힌 건 예외함에 올리고 그 단계의 다른 일을 계속한다.
