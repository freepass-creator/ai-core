```js
import { 쓴다 } from '../lib/쓴다.mjs';
await 쓴다('sheet:<id>', '무엇을 하는지', async () => { …그냥 쓴다… });
```

승인·작업번호·「코덱스만」이 다 빠졌다. 남은 잠금은 **권한이 아니라 차례**다 —

막히면 `node scripts/잠금.mjs`. 작업대장은 증적이 필요한 큰 변경에만 쓰는 **선택**이 됐다.
