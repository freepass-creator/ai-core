# ★공통후보-지도 — `lib/*.mjs` 가 «공용 인프라」 인가 «프리패스 업무」 인가

★이 문서는 **AI Core 그룹본부 모델**(`C:\dev\ai-core-control-tower\docs\GROUP_OPERATING_MODEL.md`)이 요구하는
「무엇이 여러 회사가 같이 쓸 수 있는 공용 도구고, 무엇이 프리패스만의 업무 규칙인가」를 나누는 자리다.
**문서만 둔다 — 코드는 옮기지 않는다.** `lib/` 물리 위치는 그대로다.
