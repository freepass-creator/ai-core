# 코덱스 오더 — 제미나이 API에 결제 붙이기

**왜**: 고지서 OCR이 하루 한도(무료 등급)에서 막혔다. 204장 중 34장만 읽고 429.
**끝나면**: 남은 170장을 20분에 읽는다. 앞으로 매달 수백 장이 막힘 없이 돈다.

---

## 지금 상태 (사실)

```
키       : teamjpkwork/.env.local 의 GEMINI_API_KEY (AQ. 로 시작, AI Studio 키)
소유     : 대표 개인 계정
막힌 것  : gemini-3.7-flash · 3.6-flash · 3.5-flash · 3.1-pro-preview  → 429
남은 것  : gemini-3-flash-preview · 3.5-flash-lite · 3.1-flash-lite    → 200
에러     : quotaId = GenerateRequestsPerDayPerProjectPerModel-FreeTier
```

**하루 한도이고 모델마다 따로다.** 병렬을 올려도 안 풀린다.

---

## 할 일

### ① 키가 어느 GCP 프로젝트인지 찾는다

https://aistudio.google.com/apikey

키 목록에서 `AQ.Ab8…` 로 시작하는 키를 찾아 **어느 프로젝트에 속하는지** 적는다.
(AI Studio 키는 반드시 GCP 프로젝트 하나에 붙어 있다)

### ② 그 프로젝트에 결제 계정을 연결한다

https://console.cloud.google.com/billing

- 대표 계정에 **이미 결제 계정이 있으면** → ①에서 찾은 프로젝트에 연결만 하면 된다
- **없으면** → ★여기서 멈추고 대표에게 알린다. 카드 입력은 대표가 직접 한다

### ③ 유료 등급이 됐는지 확인한다

```bash
cd /c/dev/teamjpkwork
GK=$(grep -oE "^GEMINI_API_KEY=.*" .env.local | cut -d= -f2-)
curl -s -o /dev/null -w "%{http_code}\n" \
  -X POST "https://generativelanguage.googleapis.com/v1beta/models/gemini-3.7-flash:generateContent?key=$GK" \
  -H "Content-Type: application/json" -d '{"contents":[{"parts":[{"text":"hi"}]}]}'
```

**200 이 나오면 된 것이다.** (429면 아직 무료 등급)

---

## 하지 말 것

- ★**새 키를 만들지 마라.** 키를 바꾸면 `.env.local` 을 고쳐야 하고, 옛 키가 어디서 쓰이는지 모른다
- ★**모델 이름을 코드에 박지 마라.** 사다리가 이미 있다 (`app/api/ocr/extract/route.ts` 의 `사다리`)
- ★**카드번호를 채팅·파일·커밋에 적지 마라**
