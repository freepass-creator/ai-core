**주인은 코덱스**(실행하는 쪽이 절차를 제일 잘 안다). 구조가 바뀌는 것만 Claude 검토 → [../BOUNDARY.md](../BOUNDARY.md)

## 실행 표기 규칙

SOP의 `node ...` 명령은 절차를 설명하는 것이지, 외부 변경을 직접 허용하는 명령이 아니다.

- 읽기·로컬 분석·DRY RUN은 A/B로 Codex가 실행할 수 있다.
- Sheet·Drive·데이터센터를 바꾸는 명령은 D등급이다. 정확한 명령·스크립트·리소스를 작업대장에 등록하고 Claude DESIGN/FINAL과 대표의 직전 승인 뒤 `scripts/with-lease.mjs`로만 실행한다.
- 새 트리거·권한·리소스·자동화를 넣는 SOP 변경은 C등급 구조 변경이다.

상태: ✅ 있음 · 🟡 초안 · ⬜ 없음(적어야 함)
