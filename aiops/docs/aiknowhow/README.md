## 읽는 순서와 상태

관련 주제의 **언제 쓰는가 → 핵심 원칙 → 실제 절차 → 잘못된 예 → 체크리스트** 순서로 읽습니다. 문서에 있는 예제가 현재 계정에서 작동한다는 뜻은 아닙니다. `과거 관찰`, `미실시`, `재검증 필요`, `사용 중지`를 확인하고 필요한 범위만 검증합니다. 구체적인 기준은 [공통 규격](규격.md)에 있습니다.

새 세션에 사용할 요청:

> 노하우 README에서 이번 목적에 맞는 주제만 읽어. 현재 정본·버전·적용 범위와 프로젝트 규칙을 확인하고, 과거 성공과 이번 검증을 구분해서 진행해. 새 교훈은 기존 항목부터 찾아 중복 없이 정리해.

실행 명령을 README에 반복하지 않습니다. 기존 사례의 일반 원칙은 같은 파일 안에서 연결하고, 과거의 위험하거나 잘못된 처방은 현재 절차로 제공하지 않습니다. 전체 이전 세션을 모두 회수했다고 주장하지 않습니다.
