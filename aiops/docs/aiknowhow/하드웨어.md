## KH-033 GPU·RAM을 현재 상태로 판단

출처: T5, U1, L1.
상태: 과거 기록을 바탕으로 정리한 권장 절차(이번 실행 재현 없음).
현재 열람: 2026-09-08의 KB 스냅샷 전체 읽기. 이전 세션 원문 재검수는 아님.
마지막 실행 검증: 미실시. 원문 재열람은 당시 실행 결과의 재현 검증을 뜻하지 않는다.

### 언제 쓰는가

로컬 전사·이미지 생성·대규모 파싱을 실행할 때.

### 핵심 원칙

과거 사양과 속도를 현재 환경의 보증으로 쓰지 않는다. 단순 문서 작업에 GPU를 억지로 사용하지 않는다.

### 실제 절차

1. 시스템 총/가용 RAM, GPU·VRAM·드라이버를 확인한다.
2. 공식 지원 경로와 CPU/GPU 이점을 확인한다.
3. 여유를 남겨 작은 배치/워커로 시작한다.
4. 대체로 총량의 70~80% 이내를 목표로 하되 실제 부하에 맞춘다.
5. 사용률·온도·메모리 부족·응답 저하를 관찰한다.
6. 모델 해시·기초 테스트 뒤 실제 결과물 한 건을 확인한다. 사용자 앱을 임의 종료하지 않는다.

### 잘못된 예

예전 RTX 사양이나 “1시간 음성은 6분” 기록을 보장값으로 안내한다.

### 체크리스트

- [ ] 현재 총량·가용량을 확인했는가
- [ ] 실제 생성/전사 한 건이 끝났는가
- [ ] 자원 부족을 완료로 숨기지 않았는가
