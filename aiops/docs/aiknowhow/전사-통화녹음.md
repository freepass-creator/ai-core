## 언제 쓰는가

통화·회의 녹음에서 검토 가능한 텍스트와 시간 위치를 얻을 때 사용합니다.

## 핵심 원칙

전사 결과는 후보이며 사람 이름·상호·금액·기한·사건번호는 원음 확인 전 확정하지 않습니다. 화자 구분이 없는 모델 출력에서 한 줄 전체를 한 사람의 발언으로 가정하지 않습니다.

민감 녹음은 현재 승인된 처리 위치와 보관 규칙을 따릅니다. 로컬 도구라면 녹음이 외부 API로 전송되지 않는지 확인하며 모델 다운로드와 음성 업로드를 구분합니다.

## 실제 절차

1. 사용자가 지정한 파일·폴더만 선택합니다. 인자 없는 스크립트가 다운로드·메신저 폴더 전체를 훑는다면 승인 범위를 초과하므로 자동 실행하지 않습니다.
2. 현재 faster-whisper·오디오 디코더·모델·드라이버 지원과 RAM/VRAM 가용량을 확인합니다. 과거 GPU 종류·패키지 버전·전사 속도를 현재 보장값으로 쓰지 않습니다.
3. 작은 샘플로 모델·언어·compute type을 검증한 뒤 배치를 늘립니다. GPU 경로 사용 여부와 실제 결과물 생성까지 확인합니다. CPU fallback이면 품질·속도 차이를 기록합니다.
4. 원본은 보존하고 출력 텍스트에 파일명/해시·모델·언어·시간 구간·실행 상태를 연결합니다. 이미 처리한 파일을 건너뛰는 기준이 파일명뿐인지 내용 해시/설정까지 포함하는지 봅니다.
5. 화자가 섞였거나 단위가 뭉개진 구간은 원음으로 돌아갑니다. 문맥상 그럴듯하다는 이유만으로 이름이나 금액을 임의 수정하지 않습니다.
6. 원음 재청취 후에도 모르면 미확인으로 남깁니다. AI 교차 추출은 후보 검수이며 다수결을 확정 근거로 쓰지 않습니다. [AI 교차검증](AI-교차검증.md)
7. 처리된 녹음/텍스트를 업무별 승인 경로로 정리합니다. 인박스는 대기 경로로 쓰되 이동·삭제는 별도 승인과 복구 범위를 확인합니다. 일시 파일·민감 평문은 보관 정책에 따라 관리합니다.

## 잘못된 예

- 과거 샘플 속도로 모든 한 시간 녹음의 완료 시간을 보장합니다.
- 자동 전사한 사람 이름을 문맥만으로 확정합니다.
- 상담원 견적 예시를 고객 희망 조건으로 기록합니다.
- 인자 없는 도구로 모든 다운로드 녹음을 처리합니다.
