# 연결 상태 — 되는 것 · 안 되는 것

[목차](README.md)

**세션마다 새로 발견하고 매번 "죄송합니다, 이게 안 되네요"를 반복하지 않으려고 만든 문서.** 확인된 사실만 적는다. 안 되는 걸 시도하기 전에 여기부터 본다. 새로 확인되면 그 자리에서 이 문서를 고친다 — 딴 데 새로 적지 않는다.

## AI CLI

| 도구 | 상태 | 확인 방법 |
|---|---|---|
| Gemini CLI | ★된다 | `gemini --skip-trust -p "…"` — 유료 구독·oauth |
| Cursor Agent CLI | ★된다 | `"$LOCALAPPDATA/cursor-agent/cursor-agent.cmd" --mode ask -p "…"` — **긴 프롬프트는 개행을 없애고 한 줄로 압축해서 넘겨야 한다**(여러 줄 문자열을 그대로 넘기면 Windows cmd 래퍼에서 깨져서 프롬프트를 못 읽는다, 2026-09-16 확인) |
| Codex CLI(= GPT 연결 통로) | ★**정정(2026-09-16 직접 검증)** — 로그인 돼 있고(`codex login status` → "Logged in using ChatGPT"), `api.openai.com`도 도달된다(401=인증실패였지 차단 아니었음). "네트워크 차단"은 검증 안 하고 퍼진 잘못된 정보였다. 실제 원인은 **사용량 크레딧 소진** — 2026-09-16 실측 에러: 「usage limit, try again at Sep 20th 2026 6:56 PM」. 그 시각 이후 다시 시도 | `codex exec --sandbox read-only --ephemeral "질문"` — read-only+ephemeral로 파일 안 건드리고 물어볼 수 있다. 긴 프롬프트도 표준입력/인자로 그대로 됨(cursor-agent 같은 개행 버그 없음, 미확인이었으면 직접 짧게 테스트해서 확인할 것) |
| ChatGPT/GPT 실시간 연락 | 위와 동일 — Codex CLI 크레딧 복구(9/20 18:56)까지는 실시간 못 부른다. 그 전까지는 GitHub(`freepass-creator/ai-core` main)에 질문을 문서로 남기고 대표가 ChatGPT 웹에 붙여넣어 받아오는 비동기 경로만 있다 |

## Claude Code 자체 권한(auto mode classifier)

| 무엇 | 상태 | 확인 방법 |
|---|---|---|
| `gh pr merge`(main 직접 병합), 실제 메일 발송 등 **눈에 보이는/되돌리기 어려운 명령** | ★**채팅에서 "권한 줄게"라고 말해도 안 풀린다**(2026-09-16 두 번 확인 — 메일 발송, PR merge 둘 다) | Claude Code 앱 자체의 permission 분류기가 막는 것이라, 대화 승인과 별개다. 뚫는 방법: ① 그 명령 실행 순간 뜨는 승인 팝업에서 직접 클릭 ② `/permissions` 또는 `.claude/settings.json`에 해당 Bash 규칙을 미리 추가 ③ 안 되면 GitHub 웹 등에서 사람이 직접 누른다. **다시 시도하기 전에 이 셋 중 하나가 됐는지부터 확인** — 말로 승인은 안 통한다는 걸 또 발견하는 데 시간 쓰지 않는다 |

## 외부망

| 무엇 | 상태 |
|---|---|
| `api.openai.com` | ★**차단 아니다**(2026-09-16 직접 확인) — curl 이 **401**(인증실패)을 돌려준다. 403 이 아니다. 위 「AI CLI」 표의 정정과 같은 건이다. ★이 줄에 예전에 「차단(조직 egress 정책, 403)」 이라 적혀 있었다 — 검증 안 한 서술이었고, 같은 문서 위아래가 서로 다른 말을 하고 있었다. 실제 막힌 것은 **Codex 크레딧 소진**(9/20 18:56 까지) |
| Firebase 직접 API 호출 (일부 경로) | 차단 사례 있음(맥락에 따라 다를 수 있음 — 시도 전 확인) |
| `ironrentcar.com` | 차단 사례 있음 |

## 이 표에 없는 걸 시도하다 안 되면

1. 먼저 정확한 에러(403/404/timeout/모듈없음)를 확인한다.
2. 이 문서와 [보안권한](보안권한.md)에 이미 답이 있는지 본다.
3. 없으면 실제로 확인한 뒤 **이 표에 바로 추가한다** — 다음 세션이 또 같은 삽질을 안 하도록.
