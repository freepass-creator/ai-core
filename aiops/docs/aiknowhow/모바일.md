## KH-027 기기별 조작과 결과 검증

출처: T4, L3; 신규 권장 절차.
상태: 과거 기록을 바탕으로 정리한 권장 절차(이번 실행 재현 없음).
현재 열람: 2026-09-08의 KB 스냅샷 전체 읽기. 이전 세션 원문 재검수는 아님.
마지막 실행 검증: 미실시. 원문 재열람은 당시 실행 결과의 재현 검증을 뜻하지 않는다.

### 언제 쓰는가

모바일에서 요청·촬영·확인하고 PC에서 편집·개발을 이어갈 때.

### 핵심 원칙

기능 제공 여부는 현재 앱·버전·도구로 확인한다. 모바일 지원과 PC 로컬 파일 접근은 별개다.

### 실제 절차

1. 모바일은 참조 업로드·짧은 수정 지시·승인에 필요한 정보를 한 화면에 준다.
2. PC에서는 여러 참조 비교·파일 구조·정밀 검수에 집중한다.
3. 같은 프로젝트/작업/파일 버전인지 확인한다.
4. UI는 좁은 폭에서 스크롤·모달·키보드·터치 영역을 검사한다. viewport 자체가 0인 숨겨진 화면 측정은 유효한 폭 검사로 세지 않는다(L5).
5. 저장/삭제/승인 같은 실행 버튼은 뜻이 보이게 하고 단순 아이콘으로 숨기지 않는다.
6. 확대·긴 한글·빈 데이터·오류·가로세로 전환을 확인한다.

### 잘못된 예

PC에서 보인 로컬 파일이 모바일에도 자동 공유된다고 가정하거나 모든 버튼을 아이콘만으로 바꾼다.
