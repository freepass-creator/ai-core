## KH-021 메모리는 원본으로 가는 지도

출처: M1, M2, U1.
상태: 과거 기록을 바탕으로 정리한 권장 절차(이번 실행 재현 없음).
현재 열람: 2026-09-08의 KB 스냅샷 전체 읽기. 이전 세션 원문 재검수는 아님.
마지막 실행 검증: 미실시. 원문 재열람은 당시 실행 결과의 재현 검증을 뜻하지 않는다.

### 언제 쓰는가

이전 결정·명령·실패를 회수할 때.

### 핵심 원칙

메모리와 요약은 정본을 찾는 단서다. 과거 수치·권한·배포 상태를 현재 사실로 단정하지 않는다.

### 실제 절차

1. 주제와 경로 키워드로 메모리 인덱스를 좁게 검색한다.
2. 연결된 관련 기록만 읽는다.
3. 원문 또는 현재 파일에서 핵심을 재확인한다.
4. 재확인이 안 되면 날짜와 “과거 기록”을 표시한다.
5. 재사용 절차는 공용 KB에, 일회성 결과는 작업 기록에 둔다.
6. 영구 메모리 변경은 해당 환경 규칙과 사용자의 명시 요청을 따른다.

### 잘못된 예

기억에 “배포 검증 통과”가 있다는 이유로 새 배포도 통과라고 말한다.
