## KH-015 템플릿 구조를 보존하는 발표자료

출처: U1; 신규 권장 절차.
상태: 과거 기록을 바탕으로 정리한 권장 절차(이번 실행 재현 없음).
현재 열람: 2026-09-08의 KB 스냅샷 전체 읽기. 이전 세션 원문 재검수는 아님.
마지막 실행 검증: 미실시. 원문 재열람은 당시 실행 결과의 재현 검증을 뜻하지 않는다.

### 언제 쓰는가

PowerPoint나 Google Slides로 설명 자료를 만들 때.

### 핵심 원칙

디자인만 닮게 만들지 말고 정보의 비교축·순서·관계도 보존한다. 기존 원본 템플릿을 우선한다.

### 실제 절차

1. 슬라이드 스킬과 템플릿을 읽고 슬라이드별 목적을 정한다.
2. 원본 차트의 수치·단위·기간·분모를 고정한다.
3. 제목→핵심 메시지→근거 순으로 배치한다.
4. 전 슬라이드를 렌더하여 한글 폰트·오버플로·겹침·차트 레이블을 확인한다.
5. 편집 가능한 파일과 미리보기/필요한 PDF를 함께 제공한다.
6. 연결 Slides 실제 변경은 대상과 수정 범위 승인 후 진행한다.

### 잘못된 예

사진 한 장으로 표를 대체해 편집성을 잃거나, 차트 축을 잘라 개선 폭을 과장한다.

### 체크리스트

- [ ] 원본 비교축을 유지했는가
- [ ] 수치·단위·기간이 명시됐는가
- [ ] 모든 페이지를 눈으로 확인했는가
- [ ] 편집 가능한 결과가 있는가
