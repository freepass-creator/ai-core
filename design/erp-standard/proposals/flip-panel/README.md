# 시안 G — 뒤집히는 패널 (후보, 유력)

대표 2026-09-24 「화면 전환이 최대한 없이 … 상품을 찾아서 상세 내용을 확인하고 접수하기를 누르면
그 상세 내용이 그 패널이 접수하기로 확 뒤집히는 거지 거기서 취소를 하든지 저장을 하든지 저장을 누르면
접수 목록으로 가서 그 접수된 목록이 현재 어떤 상태인지를 명확하게 알려주는 그런 화면」.

시안 F(화면 세 장이 다 바뀜)를 좁혀서 **화면은 실제로 두 장뿐**이다.

## 동선

```
① 상품찾기 — 목록(왼쪽) + 오른쪽 패널(상세 · 기간)
   패널에서 「접수하기」 → 같은 자리에서 패널이 뒤집힌다(browse.html → flip.html, 자리 · 크기 그대로)
   뒤집힌 패널 = 접수 카드(차 · 요금 영수증 + 고객 · 영업 폼)
     ├─ 「취소」 → 도로 뒤집혀 상세로(browse.html)
     └─ 「접수 저장」 → ② 계약접수 목록으로 이동(list.html)
② 계약접수 — 방금 저장한 줄이 초록 테두리 + 진행 단계가 펼쳐진 채로 맨 위에 있다
```

| 화면/상태 | 파일 | 그림 |
|---|---|---|
| ① 목록 + 상세(보기 면) | [`browse.html`](browse.html) | `../../images/proposal-flip-panel-browse.png` |
| ① 같은 화면, 패널이 뒤집힌 접수 면 | [`flip.html`](flip.html) | `../../images/proposal-flip-panel-flip.png` |
| ② 계약접수 — 방금 접수의 상태가 펼쳐져 있음 | [`list.html`](list.html) | `../../images/proposal-flip-panel-list.png` |

## 패널의 두 면

같은 카드, 같은 자리, 같은 크기 — 내용만 바뀐다(실제로는 짧은 뒤집기 애니메이션을 붙인다).

| 보기 면(browse) | 접수 면(flip) |
|---|---|
| 사진 · 이름 · 차번 · 상세 | 작게 줄인 차 요약(뒤집기 전 카드 그대로 보이게) |
| 기간 카드 3장(기간 · 남는 것 · 요금) | 고른 기간의 영수증(월 대여료 · 보증금 · 청구 · 지급 · 남는 것) |
| 우대조건 · 정책 | 고객 · 영업채널 · 담당(이전 고객 자동) · 결제 · 계약방식 |
| 「접수하기」 한 단추 | 저장 전 확인 줄 + 「취소」 · 「접수 저장」 두 단추 |

파랑 테두리 + "뒤집힘 — 취소하면 상세로 돌아갑니다" 표시로 지금 어느 면인지 분명히 한다.

## 계약접수 목록 — "지금 어떤 상태인지 명확하게"

- 맨 위에 초록 안내 줄: "방금 접수 저장됨 — 쏘렌토 MQ4 PE · 김민수 · FP-2609-0143 · 시각 · 담당".
- 방금 저장한 **그 줄만** 진행 단계(접수 → 계약서 → 인도 → 청구 → 수금·지급)를 펼쳐서 보여준다 — 지금 "계약서" 앞에 있다는 게 숫자·색으로 바로 보인다. 그 줄에서 바로 "계약서 받음으로" 처리도 가능.
- 다른 줄은 평소처럼 접힌 카드(시안 F 의 줄 카드 그대로).

## 공통

- 요약 카드 · 대수 카드 없음. 모든 덩어리 = 카드.
- 위 메뉴는 상품찾기 · 계약접수 · 실적 · 정산관리, 전자계약은 점선.
- 시안 E(카드가 화면 안에서 펼쳐짐) · F(화면 세 장) · G(패널이 두 면으로 뒤집힘, 화면 두 장) 세 갈래가 이제 다 있다. G 가 대표 요청에 가장 가깝다.
