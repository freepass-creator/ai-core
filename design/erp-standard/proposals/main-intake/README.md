# 시안 E — 메인 = 차 찾고 접수까지 한 화면 (후보)

대표 2026-09-24 「한 화면에서 차 찾고 접수해서 저장하는 화면이 메인이어야 하는데 … 아예 새롭게 다시」.

**어드민을 열면 이 화면이다.** 다른 판(계약접수 · 실적 · 정산관리 · 전자계약)은 위 오른쪽 작은 링크와 오른쪽 «다른 일» 카드로만 간다.

## 동선 — 화면을 한 번도 옮기지 않는다

```
큰 검색창에 차명 · 차번 · 공급사  →  조건 칩(기간 · 월 대여료 · 출고 · 조건)  →  결과 카드(남는 것 많은 순)
  →  «접수하기» 누르면 그 카드가 그 자리에서 접수 카드로 펼쳐짐
       1 기간 · 요금(기간마다 남는 것)  |  2 고객 · 영업(이전 고객 → 채널 · 담당 자동)  |  3 확인 · 저장(청구 · 지급 · 남는 것 · 중복 · 요금 확인)
  →  «접수 저장»  →  카드가 «✓ 접수됨 · 고객 · 시각» 으로 접히고, 오른쪽 «오늘 넣은 접수» 맨 위에 올라감
  →  검색 · 조건은 그대로 — 바로 다음 차
```

| 자리 | 카드 |
|---|---|
| 가운데 위 | **큰 검색 카드** — 한 줄 검색 + 조건 칩(드롭다운 없음). 공급사 · 상품구분 · 연료는 검색창에 쳐도 됨 |
| 가운데 | **결과 카드** — 사진 · 차명 · 차번 · 출고상태 · 연식 · 주행 · 색 · 공급사 · 우대조건 · 월 대여료 · 남는 것 · «접수하기» |
| 가운데(펼침) | **접수 카드** — 세 작은 카드: 기간 · 요금 / 고객 · 영업(+ 더 넣기 · 이전 접수) / 확인 · 저장(영수증 모양 + 큰 저장 단추) |
| 오른쪽 | **오늘 넣은 접수**(누가 · 무슨 차 · 시각 · 다음 할 일) · **다른 일**(판 링크) · 단축키 |

- 요약 카드 · 대수 카드 없음. 결과 줄의 «조건에 맞는 차 N대» 만.
- 단축키: `/` 검색 · `↑↓` 차 고르기 · `Enter` 펼쳐 접수 · `1~3` 기간 · `Ctrl+Enter` 저장 · `Esc` 접기.
