# 시안 F — 화면 세 장, 실제로 전환된다 (후보)

대표 2026-09-24 「한 화면에서 상품을 찾고 상세내용을 확인하고 거기서 기간을 선택하고 접수하기 누르면
접수화면으로 전환되서 접수저장을 누르면 접수목록으로 가는거지」.

시안 E(한 화면 안에서 카드가 펼쳐짐)와 달리 이건 **진짜 화면 전환** 이다 — 기능 쪽 실제 동작(상품찾기 → 신규 접수 폼 → 접수 목록)과 같은 구조를 카드로 다시 그렸다.

## 동선 — 화면 세 장

```
① 상품찾기 (finder.html)                         ② 접수 (intake.html)              ③ 계약접수 (list.html)
 한 화면 = 목록(왼쪽) + 상세(오른쪽)                차 · 요금은 그대로 실려 옴          방금 저장한 접수가 맨 위,
 상세에서 기간을 고른다 → 「36개월로 접수하기」  ──▶ 고객 · 영업만 넣는다 → 「접수 저장」 ──▶ 초록 테두리 + «방금 접수»
```

| 화면 | 파일 | 그림 |
|---|---|---|
| ① 상품찾기 — 목록 + 상세 한 화면 | [`finder.html`](finder.html) | `../../images/proposal-screen-flow-finder.png` |
| ② 접수 — 차 · 요금은 실려 있고 고객만 | [`intake.html`](intake.html) | `../../images/proposal-screen-flow-intake.png` |
| ③ 계약접수 — 방금 접수가 맨 위 | [`list.html`](list.html) | `../../images/proposal-screen-flow-list.png` |

## ① 상품찾기

왼쪽은 차 타일 카드 격자(사진 · 이름 · 차번 · 월 대여료), 오른쪽은 고른 차의 상세 카드 — 같은 화면 안에서 오른쪽만 바뀐다.
상세 카드 안에 **기간 카드 3장**(기간 · 남는 것 · 요금)이 있고, 고르면 아래 큰 단추가 그 기간으로 바뀐다: 「36개월로 접수하기 ›」.

## ② 접수

이 단추를 누르면 실제로 다른 화면(`intake.html`)으로 넘어간다. 왼쪽에 고른 차 · 기간 · 요금 · 남는 것이 영수증 카드로 고정되어 있고,
오른쪽 폼 카드에는 **고객 · 영업채널 · 담당만** 넣으면 된다(이전 고객이면 채널 · 담당 자동, 이전 접수 이력도 보임).
아래 확인 문구와 「접수 저장 ›」.

## ③ 계약접수

저장하면 실제로 목록 화면(`list.html`)으로 넘어가고, 방금 넣은 접수가 **맨 위에 초록 테두리 + «방금 접수»** 로 와 있다.

## 공통

- 요약 카드 · 대수 카드 없음. 화면의 모든 덩어리 = 카드(시안 C · D 의 카드 규칙 그대로).
- 위 메뉴는 상품찾기 · 계약접수 · 실적 · 정산관리, 전자계약은 점선으로 따로.
- 시안 E(한 화면 안 펼침)와 F(진짜 전환) 중 하나를 고르면 그걸로 규격 부품을 확정한다.
