# 시안 C — FreePass Admin 맞춤형 (후보)

대표 2026-09-23 「프리패스 어드민 UI UX 에 맞는 시안을 하나 더 … 아예 맞춤형으로」.
규격(`../../erp.css` · 토큰 · 긴 카드 §5-3)을 그대로 쓰고, 이 제품에만 필요한 틀 세 가지를 `admin-fit.css` 에 더했다.

| 틀 | 클래스 | 무엇이 다른가 |
|---|---|---|
| 흐름 메뉴 | `fpa-flow` | 좌측 메뉴 대신 상품찾기 → 계약접수 → 실적 → 정산관리 를 번호 붙은 길로. 전자계약은 오른쪽에 «흐름과 별도» |
| 할 일 묶음 | `fpa-queue` · `fpa-act` | 목록을 날짜가 아니라 다음에 할 일(계약서 받기 · 인도하기 · 청구하기 · 수금·지급 확인)로 묶고, 카드마다 그 일을 하는 단추 |
| 처리 서랍 | `fpa-drawer` | 고른 건을 목록 옆에서 바로 처리(차량번호 · 인도일 · 취소 · 이력). 주 단추 = 다음 걸음 |

- 요약 카드 · 대수 카드는 없다(대표 지시). 제목 → 검색 → 할 일 묶음.
- 그림: `../../images/proposal-admin-fit.png`. 채택되면 틀을 `erp.css` 추가 부품으로 옮기고 어드민에 입힌다.
