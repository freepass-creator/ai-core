# 시안 I — 조립되는 패널 3개, 상품찾기는 미니멀 (후보, 유력)

대표 2026-09-24 「여러 화면을 만들면 안 되니까 … 패널을 조립할 거야, 각 페이지를 구성하는 패널이 있는데.
상품찾기 패널 — 검색창과 필터 버튼이 있고 퀵 필터 버튼이 있잖아. 심플하게 미니멀라이즈.
상품목록 패널 · 상세내용 패널 · 접수목록 패널」.

시안 H(패널 3개)의 방향은 맞되, ① 패널의 무거운 필터 묶음(칩 여러 줄 · 슬라이더)을 걷어내고
**검색창 + 필터 버튼 + 퀵 필터 칩** 한 줄로 미니멀라이즈했다(규격 §5-1 그대로). 상세 필터는 버튼 뒤에 접어 둔다.

## 세 패널 — 조립 부품

| 패널 | 머리 | 몸통 |
|---|---|---|
| ① 상품목록 | — | 검색창 + 「필터」 버튼(한 줄) → 퀵 필터 칩(전체 · 즉시출고 · 출고가능 · 36개월 · 80만원 이하) → 좁은 줄 카드 목록 |
| ② 상세내용 | "고른 상품" / "필수 3/3" | **두 면**: 보기 면(사진 · 상세 · 기간 카드 3장 · 「접수하기」) ↔ 접수 면(뒤집으면 영수증 + 고객 · 영업 폼 + 「취소」·「접수 저장」) |
| ③ 접수목록 | 건수 | 세그(전체 · 당월접수 · 미완료) + 상태 줄 카드. 방금 저장한 줄만 진행 단계가 펼쳐짐 |

## 동선

```
① 목록에서 차를 고른다 → ② 상세내용에 그 차가 뜬다(기간을 고른다) → 「접수하기」
  → ② 가 그 자리에서 뒤집혀 접수 면이 된다(고객 · 영업만 채움)
    ├─ 「취소」 → ② 가 도로 뒤집혀 보기 면으로
    └─ 「접수 저장」 → ③ 접수목록 맨 위에 방금 접수가 진행 단계 펼친 채로 나타난다(화면은 그대로)
```

화면은 한 장뿐이다. 세 패널은 각자의 조립 부품으로, 다른 페이지(예: 실적 · 정산관리)를 만들 때도
③ 접수목록 자리에 다른 목록 패널을 갈아 끼우는 식으로 재사용한다.

## 공통

- 요약 카드 · 대수 카드 없음.
- ①③ 은 규격 카드 규칙(줄 카드) 그대로, ② 만 두 면을 갖는 특수 패널.
