# 시안 D — 카드만 (후보)

대표 2026-09-23 「카드타입으로만 시안 하나 더」. 칸 · 판 · 표 · 좌측 메뉴 없이 **바탕 위에 카드만** 놓는다. 동선은 시안 C 와 같다(상품 → 접수 한 화면).

| 자리 | 카드 |
|---|---|
| 맨 위 | **흐름 카드 4장** — 1 상품찾기(지금, 파랑으로 꽉 참) · 2 계약접수 · 3 실적 · 4 정산관리. 전자계약은 점선 카드로 따로 |
| 왼쪽 위 | **검색 카드** — 검색창 · 상세 필터 · 건 조건 칩 · 출고상태 탭 |
| 왼쪽 | **차 타일 카드 격자** — 사진 띠(출고상태 · 차량번호 · 공급사) · 차명 · 월 대여료 크게 · 연식 · 주행 · 색 · 우대조건 · **남는 것**. 고른 차 = 굵은 파랑 테두리 + «✓ 골랐음» |
| 오른쪽 | **접수 카드 더미** — ✓ 고른 차 → ✓ 기간 · 요금(기간 카드 3장, 남는 것 · 최고) → 3 고객 · 영업(이전 고객이면 채널 · 담당 자동) → 4 확인 · 저장(청구 · 지급 · 남는 것 · 중복 · 요금 확인 · 필수 3/3 · 접수 저장) |

- 시안 C(긴 카드 목록 + 세 칸)와 달리 차를 **타일로 훑어** 고른다 — 사진 · 값 · 남는 것이 한눈에.
- 요약 카드 · 대수 카드는 없다.
