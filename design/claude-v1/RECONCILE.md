## 4. 그래서 어떻게 할 것인가 (제안)

**Claude v1 을 «별도 시스템»으로 두지 않는다.** 헌법의 10단 순서에 얹는다:

1. **토큰** — Claude v1 이 새로 만든 값(글자 7단 · 모서리 4값 · 다크 램프 · 목록 박스 · 체크 표식 면)을 `design-system/tokens.json` 에 **추가**한다. 이름은 정본 규칙(`--color-*`, `--font-size-*`, `--radius-*`)을 따른다. 강조색은 정본의 파랑을 쓴다.
2. **상호작용 계약** — 「목록의 한 건은 박스」, 「상태 사다리 4단」, 「모서리가 분류를 나른다」를 `design-system/interaction.contract.json` 의 규칙으로 올린다.
3. **부품** — `claude-v1.css` 의 새 부품(체크 표식·스위치·탭·뱃지·단계·타임라인·목록줄)을 기존 기능 등록부(`registry/ui-ux-features.json`)의 기능 ID 에 매핑한다. 등록부에 없는 것만 새 기능으로 추가한다.
4. **검사기** — `scripts/check-claude-v1.mjs` 의 9항목을 기존 `uiux:validate` 계열로 옮긴다. 검사가 두 벌이면 둘 다 안 돌게 된다.
5. **화면** — `examples/claude/*` 는 **제안 화면**으로 남기고, 정본 예제(`examples/ui-shell-*`)와 하나로 합친다.

**버리는 것**: `--c-*` 이름 체계, 인디고 강조색, 별도 검사기.
**남기는 것**: 글자 7단, 모서리 4값, 다크 램프, 상태 사다리, 목록 박스 규칙, 체크 표식, 컨셉 문서, 결정 로그.
