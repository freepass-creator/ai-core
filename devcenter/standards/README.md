# DevCenter Control Plane standards

이 경로는 별도 공통 규격 정본이 아니다. 현재 규칙은 AI Core 루트에서 관리한다.

- 헌법: `../../docs/AI_WORKING_STANDARD.md`
- Academy: `../../docs/AI_ACADEMY_CURRICULUM.md`
- 개발 runtime: `../../docs/DEVELOPMENT_RUNTIME.md`
- 공통 계약: `../../contracts/`
- 등록부: `../../registry/`

`cards.json`과 하위 문서는 기존 규격을 찾고 학습하기 위한 실행 자산 또는 역사 증거다. 카드 존재, 과거 승인, 로컬 경로는 현재 권한이나 구현 완료를 자동으로 부여하지 않는다.
