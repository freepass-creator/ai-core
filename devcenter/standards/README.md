# standards — Development Center Control Plane

브라우저 **규격 카드·학습**은 [카드 목록](cards.json)의 원본·scope·예제·실패 사례·검증·사용법을 보여준다. 카드의 작성 완료와 독립 검토·정식 승인은 구분한다. 집계 규칙은 [완성도 기준](../quality/COMPLETION.md)을 따른다.

상태: 7개 Hub 공통 요구사항·정본·예외를 관리하는 **Control Plane** 경로. 별도 Hub가 아니다. 실행 기능 구현·검수 완료가 아니다.

- `requirements`: 요구사항·완료 조건·승인 권한 기준
- [시작틀 후보 안내](../docs/STARTER-TEMPLATES.md): 프로젝트 시작틀 후보·제작 원칙 (실제 템플릿 미구현)
- `ssot`: 기준의 정본·승인·버전·충돌. 기존 ../../ssot/PART.md 참조

파트를 활성화할 때 책임자·입출력·원본 참조·실행 진입점·완료 기준을 명시한다. 기존 원본은 이동·복제하지 않는다.
