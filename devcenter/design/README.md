# Design Hub 실행 자산

공통 UI/UX 규칙과 값의 정본은 AI Core 루트에 있다.

- 진입점: `../../docs/UI_UX_START_HERE.md`
- 헌법: `../../docs/UI_UX_CONSTITUTION.md`
- 토큰: `../../design-system/tokens.json`
- 컴포넌트·패턴·상호작용: `../../design-system/components.registry.json`, `../../design-system/patterns.registry.json`, `../../design-system/interaction.contract.json`
- 현재 binding: `../../registry/design-hub-binding.json`

이 디렉터리는 규격값의 사본이 아니라 실행 노하우와 backing asset을 보유한다. `AI_DESIGNER_OPERATING_GUIDE.md`와 `AI_EDITORIAL_LAYOUT_COMPILER.md`는 콘텐츠 설계·페이지 제작 방법론이며 루트 UI/UX 및 제품별 브랜드 정본에 종속된다. `components/`와 `patterns/`의 기존 자산은 provenance·소비자·검증 범위를 확인한 뒤 재사용한다.

새 토큰·컴포넌트·패턴은 여기서 독립 확정하지 않는다. 루트 정본에 등록하거나 프로젝트 고유 자산으로 남길지 근거와 검증을 갖춰 결정한다.
