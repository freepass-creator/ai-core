# DevCenter 작업 시작 안내

목표는 문서를 많이 읽는 것이 아니라 현재 작업의 정본·재사용 자산·검증 경로를 짧게 고정하는 것이다.

1. AI Core 루트에서 `npm run academy:start -- --task "<사용자 결과>" --root <대상 저장소> --track <track>`을 실행한다.
2. receipt가 가리키는 헌법과 해당 track 문서만 읽는다.
3. 새 자산 전에 루트 `reuse:check`로 기존 capability와 실제 자산을 찾는다.
4. 개발 업무이면 `../../registry/work-map.json#hub_routes`에서 Primary/Secondary Hub를 확인한다.
5. UI/UX이면 `../../docs/UI_UX_START_HERE.md`와 `../../registry/design-hub-binding.json`을 따른다.
6. 대상 프로젝트의 현재 revision과 지침을 확인하고 그 프로젝트에서 작업한다.
7. 실제 테스트·브라우저·배포 readback 등 요청에 맞는 증거를 남긴다.
8. 결과를 `목적 / 대상 revision / 변경 / 검증 / 남음 / next_start_here`로 인계한다.

DevCenter는 공통 실행 노하우와 도구를 제공한다. 프로젝트 고유 업무 의미, 운영 데이터, 권한, 브랜드 원본을 가져와 두 번째 정본으로 만들지 않는다. 과거 `BASELINE.md`, `CURRENT-STANDARDS.md`, `FOUR-AI-WORKFLOW.md`는 현재 규칙 대신 루트 정본을 가리키는 호환 문서다.
