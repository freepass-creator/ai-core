# DevCenter 기본선 — 호환 진입점

상태: **COMPATIBILITY POINTER**

과거 v0.1 기본 규격의 공통 규칙은 AI Core 헌법과 Academy로 승계됐다. 이 문서는 별도 규격값이나 AI 정족수를 정의하지 않는다.

## 현재 정본

- 전체 작업 헌법: `../../docs/AI_WORKING_STANDARD.md`
- 업무별 최소 독서 경로: `../../docs/AI_ACADEMY_CURRICULUM.md`
- 개발 실행: `../../docs/DEVELOPMENT_RUNTIME.md`
- UI/UX: `../../docs/UI_UX_START_HERE.md`
- 수치·토큰: `../../design-system/tokens.json`
- 컴포넌트·패턴: `../../design-system/components.registry.json`, `../../design-system/patterns.registry.json`
- 작업 및 Hub 라우팅: `../../registry/work-map.json`

작업 시작 기록은 `academy:start` receipt를 사용하고, 결과는 루트 헌법의 `목적 / 대상 revision / 변경 / 검증 / 남음 / next_start_here` 형식으로 남긴다.

2026-09-09 당시 조사와 충돌 증거는 `baseline-sources.json`, `IMPROVEMENT-REPORT.md`, `operations/progress-handoff/`에 역사 기록으로 보존한다. 그 기록의 수치·역할·경로는 현재 규칙으로 자동 승격하지 않는다.
