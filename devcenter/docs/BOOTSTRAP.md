# Initial repository scope

2026-09-09 사용자 요청에 따라 비공개 개발센터 저장소를 준비한다.

등록 대상: 그룹/파트 골격, 안내, 기존 registry.json, 틀.mjs, 기존 ssot/PART.md와 AGENTS.md. 로컬 경로 참조는 다른 컴퓨터에서 자동으로 동작한다는 뜻이 아니다.

등록 제외: reviews 원문, runs 실행 데이터, 로컬 조사 목록, 고객자료, 인증정보, 다른 프로젝트 코드. 기존 파일과 폴더는 삭제/이동하지 않는다. .gitignore는 명시적 허용 목록이다. 새 코드는 검토 후 해당 경로를 허용해야 한다.

설계의 4-AI 최종 검수는 HOLD. 최초 등록은 사용자 승인된 비공개 골격 보관이며 실행 시스템 출시가 아니다. 부족한 부분: 실행 엔진, 자산의 인터페이스/소비자 검증, UI 갤러리, 자동 검사, 외부 AI 검토 연결.
