# DevCenter 원본 조사 기록 — 현재 권한 안내

상태: **HISTORICAL EVIDENCE INDEX / NON-NORMATIVE**

이 문서는 2026-09-09에 관측한 프로젝트별 규격과 충돌의 색인이며 현재 공통 규격을 정의하지 않는다. 당시 원본 해시와 범위는 `baseline-sources.json`, 세부 문제는 `IMPROVEMENT-REPORT.md`에 보존돼 있다.

## 현재 사용할 정본

| 목적 | 정본 |
|---|---|
| 작업 원칙·협업·권한 | `../../docs/AI_WORKING_STANDARD.md` |
| 개발 시작·재사용·검증 | `../../docs/AI_ACADEMY_CURRICULUM.md`, `../../docs/DEVELOPMENT_RUNTIME.md` |
| UI/UX 진입 | `../../docs/UI_UX_START_HERE.md` |
| 공통 UI 값 | `../../design-system/tokens.json` |
| 컴포넌트·패턴·상호작용 | `../../design-system/components.registry.json`, `../../design-system/patterns.registry.json`, `../../design-system/interaction.contract.json` |
| FreePass 제품 규칙 | `../../docs/FREEPASS_PRODUCT_UI_PROFILE.md` |
| 프로젝트·capability·라우팅 | `../../registry/projects.json`, `../../registry/capabilities.json`, `../../registry/work-map.json` |

프로젝트 고유 규칙은 각 프로젝트의 현재 revision에서 확인한다. 이 역사 문서에 기록된 FP4·WORK-ERP 수치, 컴포넌트 이름, AI 역할 또는 로컬 경로를 현재 기본값으로 인용하지 않는다. 현재 정본과 충돌하면 현재 정본이 우선하며, 프로젝트별 승인 차이는 억지로 공통화하지 않고 HOLD한다.
