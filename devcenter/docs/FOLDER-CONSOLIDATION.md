파일 이름이 한글이라 제거한 것이 아니다. 초기 구조와 현재 그룹 구조의 중복된 자리만 정리했다. 실제 검색 도구인 루트 `틀.mjs`는 유지했다. 검사기와 대상 원본 프로젝트도 이동하지 않았다.

## 검증

- 원본 README 두 개는 변경 전 SHA-256과 함께 로컬 `reviews/2026-09-09-folder-consolidation`에 보존했다. 두 파일은 원래 Git 추적 대상이 아니었다.
- 삭제 직전 원본과 보존본 해시가 일치하는지 재확인했다. 폴더는 비재귀 삭제로 비어 있을 때만 제거했다.
- 정리 후 세 경로가 없고 새 안내와 참조 대상이 존재함을 확인했다.
- `registry.json`, `틀.mjs`는 정리 전후 SHA-256 동일. `node 틀.mjs dev.design.token`은 실제 원본 경로를 찾아 종료 코드 0.
- README의 '갤러리 미구현'이라는 오래된 상태도 현재 구현된 portal 안내로 수정했다. 전체 규격 승인 HOLD는 유지했다.
- Claude 설명 기반 독립 검토에서 후보의 표준 승격 우려가 나왔다. 최종 위치를 규격 파트 대신 docs로 바꾸고, 미승인·비정본 상태를 명시했다. 로컬 보존본은 복구용이며 Git 이력을 대체한다고 주장하지 않는다.

이번 결과는 폴더 중복 정리다. 규격 의미 통합이나 네 AI의 전체 승인 완료가 아니다.
