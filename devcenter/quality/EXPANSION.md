# 기능·디자인 도구 확장 기록 — 2026-09-09

요청: 현재 프로젝트의 기능과 디자인 도구를 모두 찾아 센터에서 활용하고, 기존 50개 인수 조건의 100%를 목표로 보완한다. 원본 프로젝트는 수정하지 않는다. 수집·실행·의미 검수·승인은 분리한다.

## 이번 스냅샷

- 기능 수집: Git 작업 폴더를 포함한 C:/dev의 75개 폴더, 코드 33,858개, 이름 있는 함수 선언 201,601개. 미색인 익명 callable 330,075개, 미지원 파일 122개, 파싱 오류 후보 1개, 읽기 오류 0개. 선언 수는 독립 업무 기능 수가 아니다.
- 공개 심볼: 74,205개. 폴더 기반 UI 공개 심볼 10,088개, 상태·훅 후보 995개, 나머지 공개 값·함수·클래스·이름 있는 재수출 63,122개. 부품의 실행·의미·독립성을 판정한 숫자가 아니다.
- 원본 재대조: 33,856/33,858개 해시 일치. 조사 중 바뀐 `_wt-dict/scripts/check-ui-contract.mts`, `devcenter/scripts/verify-function-collector.mjs`는 도구 모음에서 제외했다. 변한 원본을 예전 내용으로 대체하지 않았다.
- 도구 선언: 소스 상위 경로와 프로젝트 루트에서 package.json 48개, 서로 다른 의존 도구 이름 77종. 설치·잠금 버전·라이선스 검증이 아니다. 소스 없는 깊은 패키지는 미조사다.
- 스타일: CSS/SCSS 264개(일반 포함 218, 가림 처리 46), 인라인 스타일 후보 파일 4,050개, 위치 57,074개. 가려진 소스는 실행용 코드로 표시하지 않는다.
- 생성물·민감 경로·연결 경로·크기 제한 등은 각 원본 JSON의 coverage/limitations/errors에 공개한다. 원격 전용 저장소와 다른 드라이브는 이 수집 범위 밖이다.

## 눈으로 쓰는 기능

- 부품·개발 도구 모음: 이름·프로젝트·파트 검색, 공개 심볼/의존 도구/명령 이름 전환, 원본 위치·행·SHA 확인과 참조 복사.
- 디자인 도구 실습: 글자/배경 대비, px/rem 환산, 반응형 격자·간격과 코드 복사. 값은 실험용이며 새 전역 규격으로 승격하지 않는다.
- 원본 함수 비교: 기존 kmValue/fileSizeText에 man/manWon/manShort/kmDisplay/isEvFuel을 더해 7개 원본 함수의 결과를 체험한다. 398,000의 반올림 요약과 상세·내림 표시를 나란히 보여준다.
- 외부 탐색 후보: Storybook과 Radix의 공식 설명 링크. 설치·통합·라이선스 승인을 주장하지 않는다.

대비 기준은 https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html 의 일반 글자 4.5:1, 큰 글자 3:1을 참고하며 판정 전에 반올림하지 않는다. 페이지 전체 접근성 합격은 아니다.

## 검사 근거

- scripts/verify-toolbox.mjs: 실제 임시 폴더로 wrapper/reexport, JS 안의 JSX, 문자열 오탐, 원본 변경, 프로젝트 `..`/절대경로, 외부 폴더 junction 차단, 명령 본문·URL·문자열 리터럴 비노출을 검사했다.
- scripts/verify-design-tools.mjs: 21:1/1:1, AA 경계, 잘못된 색/숫자, 격자 범위, 원본 금액·주행거리·연료 예제를 실행했다.
- scripts/verify-browser.cjs: 실제 Chromium 1440/390 화면, 탐색/검색/복사/학습/원자/신규 도구 27개 검사 PASS. 실행 trace는 reviews/expansion-browser-trace.zip에 저장하며 해시는 quality/acceptance-browser.json에 기록한다. 로컬 trace는 Git 제외다.
- 새 도구 모음의 HTTP 503과 잘못된 JSON 스키마를 실제 브라우저에서 재현했고, 오류 표시 후 재시도로 실제 목록이 돌아오는 것을 확인했다. 전체 화면의 모든 네트워크 실패 검증(D10)을 대신하지 않는다.
- 기존 타입 검사·버튼/기능 예제·학습·오래된 증거 배제·로컬 패키지 설치 검사를 다시 실행했다.

현재 고정 v1 인수 결과는 40/50, 80%다. 기본 39/40, 심화 1/10이다. D08을 실제 두 화면 너비 검사로 추가 통과했다. 항목 수를 늘리거나 분모를 줄여 100%로 만들지 않았다. 새 수집 개수도 기능 인수 점수에 더하지 않는다.

## 독립 검토와 남은 100% 조건

Claude에 collector/test/design-math/toolbox 네 파일을 독립 검토시켰다. 입력별 SHA는 quality/expansion-review-inputs.json, 원응답은 quality/expansion-claude.md다. 프로젝트 경로 이탈·상위 폴더 junction 누락은 재현 후 수정했고, 누락 범위 공개와 JSX 파일 파서를 보완했다. TypeScript 파서 사용은 신뢰한 개발 의존성을 실행하는 것이며 수집 대상 애플리케이션 실행과 구분해 설명을 고쳤다. public→static 경로 의심은 실제 빌드 복사와 HTTP/브라우저 조회로 해소했다. 수정 전 검토를 수정본 전체 합격으로 옮기지 않는다.

Cursor와 Gemini는 이번에도 실제 비대화형 호출에서 폴더 신뢰 제한으로 실패했다. reviews/expansion-cursor-error.txt 및 expansion-gemini-error.txt에 원문을 보관한다. 네 역할 전체 검수는 HOLD다.

미통과: I04(색인 원본·선언 위치의 전수 재대조), I08(별칭·재수출의 심볼 소비 그래프), S08(현역 규격의 전수 의미 판정), S09(카드 전체 독립 의미 검토), S10(승인/폐기/대체 이력 실행), R10(실제 인증/API/저장 계약), D09(키보드·확대 전수), D10(모든 주요 화면의 네트워크 실패 전수), L09(독립 AI 실무 적용 전후 평가), L10(다중 세션 실무 이력).
