HOW TO ASK

오더는 이렇게 말하면 됩니다.

“ai-core의 오더 화면을 만들어줘.
접수와 이어하기가 되면 완료야.”
“이 오더는 Claude가 설계하고
Codex가 구현, Cursor가 검토해줘.”
“아까 오더 이어서 해줘.
막힌 이유와 다음 할 일부터 알려줘.”

업무 의도를 말해주시면 됩니다. AI·도구 이름은 원하는 배정이 있을 때만 덧붙이세요. 다른 대화에서 이어갈 때는 오더 번호나 인계 자료를 함께 전달하세요.

현재 가능한 범위

이 화면과 CLI는 이 PC의 같은 원장을 사용합니다. 다른 대화·AI·메일을 자동 수집하지 않습니다. ‘결과 접수’는 담당자가 기록한 결과이며, 완료는 사용자가 근거와 완료 조건을 확인한 기록입니다. 외부 발송·결제·배포 승인을 대신하지 않습니다.
