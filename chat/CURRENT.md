# Chat 연구실 — 현재 인계 요약

갱신일: 2026-09-13
적용 범위: 현재 대화에서 확인한 AI Core 목적·연구 기록·Work 공유 방식.
상세 노트: `notes/2026-09-13-ai-essence-and-human-agency.md`

## 사용자가 명시한 방향 — USER_DIRECTIVE

- AI Core는 개발만이 아니라 문서·법률 준비·사업·운영·여행 등 다양한 인간 활동을 보좌하는 방향을 연구한다.
- 사용자의 생각을 안다고 추정하지 말고, 필요한 정보는 확인하며 더 나은 대안과 구조를 능동적으로 제안한다.
- 사용자의 의견을 그대로 따라가거나 이름·조직을 늘리는 것으로 고도화를 대신하지 않는다.
- Chat과 Work는 병렬로 작업하되 Work가 Chat의 목적·설계 근거를 읽을 수 있게 한다.
- 이번부터 이 대화의 목적·판단·연구는 메일보다 Chat 기록 공간에 남기는 것을 우선한다. 이번 요청으로 메일은 발송하지 않는다.

이 방향은 범용 보좌를 연구하라는 뜻이다. 모든 개인 계정·자료를 상시 수집하거나 모든 외부 행동을 자동 승인한다는 뜻이 아니다.

## 이번 Chat의 제안 — RESEARCH_POSITION, 미채택

중심 명제: AI의 역할은 사람의 생각과 현실의 연결을 강화하되, 사람의 실질적 선택권과 수정·철회 능력을 보존하는 것이다.

새 센터·OS·CIVILIZATION 버전을 추가하지 않는다. 다음 세 검토 대상으로 압축한다.

| 검토 대상 | 막으려는 실패 | 다음 설계에서 확인할 것 |
|---|---|---|
| 의도 가설과 확인 분리 | AI의 추정 목적이 사용자 목표로 굳어짐 | 명시 목표·추정·미확인을 기존 입력 계약이 분리하는가 |
| 기억의 범위·정정·적용 중단 | 과거의 임시 선호가 현재 작업을 계속 지배함 | 철회된 선호를 다음 작업에서 제외하고 정정을 설명할 수 있는가 |
| 준비와 확정 행동 분리 | 불필요한 전면 중단 또는 미승인 외부 실행 | 가능한 초안은 진행하고 승인이 필요한 행동만 보류하는가 |

## Work의 최소 읽기 순서

1. 현재 Work Packet과 작업 브랜치의 AGENTS를 먼저 읽는다.
2. 이 CURRENT에서 바뀐 사용자 방향만 확인한다.
3. 관련 설계에 영향을 줄 때만 상세 노트의 해당 절을 읽는다.
4. 기존 `conversation-learning`, `domain-quality`, `core` 등으로 표현 가능한지 먼저 검토한다. 이름만 다른 중복 모듈을 만들지 않는다.
5. 반영 제안은 작업 범위·기준 commit·변경 행동·검증 기준으로 반환한다. 현재 구현 범위를 자동 확대하지 않는다.

## 이번 기록의 실제 상태

- 만든 것: 연구실 안내, 현재 인계 요약, AI 본질에 대한 연구 입장 문서.
- 만들지 않은 것: 새 런타임, 자동 수집기, 상시 감시, 배포, 모델 재학습.
- 검증: 문서 검토이며 테스트 실행·독립 평가·실무 효과 검증은 아님.
- Work 수신/열람: 아직 확인하지 않음. PR 댓글로 참조 위치를 제공하는 것과 Work 실행은 별개다.
- main 병합: 하지 않음. `chat/research-notebook` 브랜치를 명시해야 이 초안 기록을 읽을 수 있다.

다음 갱신은 새 사용자 결정·실제 Work 피드백·반례·관찰 결과가 있을 때 한다. 저장된 예전 요약보다 현재 명시 지시와 최신 확인 자료를 우선한다.
