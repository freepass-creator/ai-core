# Chat 연구실

상태: 문서 기반 연구·인수인계 공간. 실행 엔진이나 자동 대화 수집기가 아니다.
관리 lane: Chat / 공유 대상: 사용자와 이 저장소 접근 권한이 있는 Work·검토자.
초기 위치: `freepass-creator/ai-core`의 `chat/research-notebook` 브랜치, `chat/` 폴더.

## 목적

사용자가 2026-09-13 현재 대화에서 요청한 방향을 반영한다. 이메일 대신 Chat에서 정리한 목적·판단·연구를 이곳에 남기고 Work가 참조하게 한다. 이 공간은 모델 내부의 숨은 기억이나 개인적 자율 공간이 아니라 사용자가 확인·수정할 수 있는 외부 기록이다.

## 먼저 읽을 것

1. `CURRENT.md`: 확정된 사용자 방향, AI 제안, 미검증 사항, Work의 최소 읽기 범위.
2. `notes/2026-09-13-ai-essence-and-human-agency.md`: AI의 역할에 관한 연구 입장과 구현 검토 과제.
3. 원문이 필요한 경우에만 CURRENT가 가리키는 소유 시스템 지침을 읽는다.

## 기록 경계

- 모든 대화를 복사하지 않는다. 현재 결정을 바꾸는 목적·정정·선호·교훈만 비식별 요약으로 남긴다.
- 사용자의 명시적 결정과 Chat의 제안·가설·비유를 구분한다. 모델의 제안을 사용자 승인으로 바꾸지 않는다.
- 현재 대화에서 보지 않은 다른 세션·프로젝트를 읽었다고 기록하지 않는다.
- 연구 본문은 사용자에게 제시 가능한 설명·결론이다. 비공개 내부 추론 기록을 저장하는 공간이 아니다.
- 사건·고객·직원·금융 원자료, 비밀값은 복사하지 않는다.
- 메일은 이번 저장 경로에서 사용하지 않는다. 기존 메일의 삭제나 기존 자동화의 변경을 의미하지 않는다.
- 이 폴더가 있다고 모든 세션이 자동으로 읽거나 기록하는 것은 아니다. 해당 세션에서 실제 조회·작성한 범위만 완료로 보고한다.

## Chat / Work 분업

Chat은 이 연구실을 편집한다. Work는 현재 Work Packet과 프로젝트 규칙을 우선하고 이곳은 다음 설계의 참고로 사용한다. 동일 구현 브랜치를 동시 수정하지 않는다. 연구 의견은 검토 후 구현 작업으로 전환하며 자동 main 병합·배포·권한 확대로 이어지지 않는다. Work의 확인 여부는 실제 응답으로만 기록한다.

## 갱신 원칙

CURRENT는 짧게 유지하고 새 정보가 기존 결정을 바꿀 때만 갱신한다. 상세 노트는 날짜와 주제로 남기며 의미 없는 버전 상승을 하지 않는다. 오래된 판단은 적용 범위·변경 이유·대체 기록을 표시한다. 사용자의 과거 한마디를 영구 성격이나 불변 목표로 만들지 않는다.

철회 요청은 최소한 이후 적용 중단과 현행 요약 정정으로 다룬다. Git 이력·백업에서의 완전 삭제는 별도 보존 정책·권한·실제 처리 확인이 필요한 문제이며 단순 표시 변경으로 완료라고 하지 않는다.
