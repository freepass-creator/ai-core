# 화면 조작 — `C:\dev\ai-ops\scripts\pc\pc.ps1` (2026-10-03 창목록·찍기·글자 실행 확인)

PowerShell 실행 정책 때문에 **그 실행에만** Bypass 를 붙인다(시스템 설정은 바꾸지 않는다):
```bash
P="powershell -NoProfile -ExecutionPolicy Bypass -File C:/dev/ai-ops/scripts/pc/pc.ps1"
$P 창목록 "ChatGPT|chrome"            # 프로세스 | 제목 | x,y,w,h
$P 앞으로 "<창제목정규식>"
$P 찍기 <출력.png>                      # 두 모니터 전체(왼쪽 모니터는 x 가 음수)
$P 글자 -창 "<창제목>"                   # 보이는 글자 + 좌표(OCR)
$P 찾기 "<글자>" -창 "<창제목>"
$P 누르기 <X> <Y> -창 "<창제목>" [-기대창 "<뜰 창>"]
$P 입력 "<글>" -앱 <프로세스>
$P 키 "{ENTER}" -앱 <프로세스>          # SendKeys 표기
$P 엑셀읽기 <파일.xlsx> [시트]           # 창 없이 옆에 .tsv
```

## 지킬 것
- **보고 → 하고 → 결과 확인.** 누른 뒤 다시 찍어 보거나 `-기대창` 으로 확인한다. 화면 글자는 앱의 상태가 아니라 «표시»다(placeholder 를 남은 글자로 읽어 성공을 실패로 찍은 적이 있다).
- 좌표는 두 모니터 가상 좌표다 — 왼쪽 모니터는 음수. 스크린샷 배율이 줄었으면 원래 좌표로 환산한다.
- ★**다른 세션·사람이 쓰는 창이면 손대지 않는다.** 앞 창이 로그인·인증·보안 확인(예: GitHub Confirm access·Device Activation) 이거나 다른 일을 하는 중이면 그 화면을 뺏지 않고 HOLD — 명령줄 길로 돌리거나 기다린다. `누르기` 가 「창 제목이 다름」으로 ABORT 하면 그게 신호다.
- 비밀번호·결제·권한 승인·외부 공개는 화면으로 대신 하지 않는다 — 사용자에게 「링크 + 이거 누르세요」 한 줄.
- 카톡 입력·키는 이 도구가 막는다 → `kakao-send`.
