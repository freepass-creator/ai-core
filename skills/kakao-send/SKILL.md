# 카톡 보내기 — `C:\dev\ai-ops\scripts\카톡-P0.ps1`

★이 스킬은 «보내는» 일이라 이 PC 에서 실제로 돌려 확인하지 않았다(2026-10-03). 정본 절차는 ai-ops 저장소 문서에 있다.

## 누가
- **카톡 응대·작업 세션만**(카톡 전용 PC `[EN1]`). 다른 세션은 보내지 않는다 → 카톡 세션에 SendMessage 로 넘기거나 `blocked-escalate`.
- 화면 도구 `pc.ps1` 은 카톡 입력·키를 막아 둔다 — 반드시 이 스크립트로.

## 어떻게
- `카톡-P0.ps1` 을 `-발화자` 와 함께 부른다(누가 말하는지 남긴다). 금지선·발화자 확인·두 번 전송 막기가 들어 있다.
- 불가 패턴(금지선)에 걸리면 **보내지 않고 멈춘다(fail-closed)** — 우회하지 않는다.
- 방 이름 = 권한. 엉뚱한 방에 보내지 않도록 방을 먼저 확인한다.

## 지킬 것
- 고객에게 가는 글은 사람에게 가는 «외부 발송»이다 — 업무 규칙이 허락한 범위·승인된 문안만.
- 대화 원문(개인정보)을 저장소·로그에 커밋하지 않는다.
- 자세한 규칙: `C:\dev\ai-ops\docs\` 의 카톡 세션 문서(`카톡-세션-직접응대.md`).
