# 비상 기능 인수 시나리오

버전: 0.2 · 2026-09-15 (Asia/Seoul)
상태: `SPECIFICATION_ONLY` — 이 표는 실행 결과가 아니다.
구현 지시: [클로드 인계서](CLAUDE_EMERGENCY_HANDOFF.md) · 절차: [비상매뉴얼](EMERGENCY_RUNBOOK.md)

## 실행 전제와 공통 기대값

모든 사례는 합성·비식별 fixture, 고정 평가 시각, 검토된 별도 정책 fixture로 실행한다. 실제 장애를 만들거나 운영 데이터·외부 계정을 연결하지 않는다. 모든 판정에서 `execution_authorized: false`, `side_effects_performed: false`, `control_enforcement: NOT_IMPLEMENTED`, `evidence_authenticity: NOT_ATTESTED`가 필요하다.

정상 fixture는 정확한 대상·revision·시각·정책·행동별 승인·필수 검사·경쟁 실행 상태·결과 대조를 모두 갖춘다. 긍정 판정도 입력상 `READY_FOR_REVIEW`까지만 허용한다. 증거의 존재/정합성 검사와 외부 사실 인증을 구분한다.

각 행은 정상 fixture에서 해당 조건만 바꾼 독립 사례다. 기대값이 여러 리소스에 걸치면 개별 판정과 전체 요약을 모두 검사한다. 별도 허용 정책이 없는 `해당 없음`은 부족 증거다.

## P0 필수 사례

| ID | 연결 요구사항 | 입력·상황 | 기대 판정과 확인할 행동 |
|---|---|---|---|
| `EMG-T01` | ER-01, ER-02, ER-10 | 정상 fixture의 모든 필수 조건이 일치 | READY_FOR_REVIEW. 네 안전 경계 필드는 그대로이며 외부 실행 없음 |
| `EMG-T02` | ER-01 | schema 버전/필수 식별자 누락, 미지원 enum, 중복 ID에 모순된 값 | INVALID. 잘못된 필드 경로와 이유 코드. 원문 입력을 오류에 노출하지 않음 |
| `EMG-T03` | ER-01, ER-02 | 정본 또는 실제 대상 revision이 UNKNOWN | HOLD. main/최신 날짜/기억으로 빈 값을 채우지 않음 |
| `EMG-T04` | ER-03 | 파싱 불가 날짜; 별도 변형으로 미래 관측 또는 만료 증거 | 파싱 불가 INVALID, 유효한 형식의 미래/만료는 HOLD. 옛 snapshot.as_of를 넣어도 평가 시각 기준 유지 |
| `EMG-T05` | ER-02 | 같은 소스 SHA이나 증거의 프로젝트·환경·리소스·대상 revision 중 하나가 다름 | HOLD. 다른 환경의 PASS를 현재 대상에 재사용하지 않음 |
| `EMG-T06` | ER-02, ER-06 | 검증 이후 원격 소스/대상 revision 또는 정책 revision 변경 | HOLD. 기존 계획·검증·승인 stale 이유 표시. 자동 rebase/merge/force push 없음 |
| `EMG-T07` | ER-04 | lease 만료 후 이전 writer가 여전히 활성이라고 관측 | 해당 리소스 HOLD. 만료만으로 경쟁 실행이 사라졌다고 보지 않음 |
| `EMG-T08` | ER-04 | 다른 AI에 중지 요청했으나 응답 없음 | HOLD. 중지 요청과 실제 중지를 구분 |
| `EMG-T09` | ER-04 | 한 PC의 중지 응답은 있으나 다른 서버의 쓰기 경로가 미확인 | HOLD. 중지 응답으로 전역 차단 완료를 선언하지 않음 |
| `EMG-T10` | ER-05 | 외부 쓰기 timeout, 실제 반영 결과 UNKNOWN | HOLD. 재실행 대신 기존 요청 읽기 대조를 다음 확인으로 제시 |
| `EMG-T11` | ER-05 | 같은 중복 방지 참조에 서로 다른 대상 또는 입력 식별값 | HOLD 및 요청 충돌 이유. 같은 실행으로 병합하거나 자동 보상하지 않음 |
| `EMG-T12` | ER-05 | 5건 중 2건 성공 확인, 1건 미실행 확인, 2건 결과 불명 | 영향 범위 HOLD. 세 상태를 보존하고 성공분 포함 전체 재전송 없음 |
| `EMG-T13` | ER-04, ER-10 | 독립 리소스 A는 경쟁 쓰기, B는 정상. 공통 의존성 없음 | 전체 요약 HOLD, A HOLD, B READY_FOR_REVIEW. B를 실제 중단/실행하지 않음 |
| `EMG-T14` | ER-06 | 차단 승인만 있고 복구 쓰기 또는 재개 승인이 필요한 정책 | 해당 행동 HOLD. 차단 승인을 복구/재개 승인으로 전용하지 않음 |
| `EMG-T15` | ER-06 | 승인 만료 또는 승인된 행동·범위·입력 식별값·실행자 불일치 | HOLD. 단순 승인 문자열의 존재로 통과하지 않음 |
| `EMG-T16` | ER-06, ER-07 | snapshot이 required=false 또는 해당 없음으로 표시하나 정책상 필수 | HOLD. 정책으로 정한 요구를 입력자가 해제하지 못함 |
| `EMG-T17` | ER-07 | 외부 부작용 없는 격리 개발의 예상 실패 테스트임이 확인됨 | 정상 개발 실패 분류. 개발 수정은 가능하다고 설명하되 승격/운영 재개 판정은 HOLD. 실제 사고를 만들지 않음 |
| `EMG-T18` | ER-07 | 읽기 조사로 사고 아님이 확인됐고 복구 불필요의 정책 근거 존재 | 사고 아님 분류. 필요한 조건이 충족되면 READY_FOR_REVIEW. 가짜 rollback/복구 영수증 요구 금지; 이후 쓰기 승인 별개 |
| `EMG-T19` | ER-10 | 필수 검사 0건, 필수 검사 생략, 실패 중 하나 | HOLD. 문서 생성·테스트 계획·검사 개수를 PASS 근거로 대체하지 않음 |
| `EMG-T20` | ER-02, ER-10 | 로컬 검사는 PASS이나 실제 배포 revision 확인 또는 정상 데이터 보존 증거 누락 | HOLD. 코드 검사로 서비스/데이터 복구 완료를 선언하지 않음 |
| `EMG-T21` | ER-09 | 합성 비밀정보 sentinel 또는 서명 URL을 입력/오류 조건에 주입 | 비허용 필드는 INVALID. stdout/stderr/결과/파일에 sentinel 원문이 없어야 함. 정규식 통과만으로 완전 비식별을 보증하지 않음 |
| `EMG-T22` | ER-08 | 입력 필드에 shell·실행 파일 경로·동적 import 지시 삽입 | 비허용 필드는 INVALID. 명령 실행·네트워크·자격증명 접근이 발생하지 않아야 함 |
| `EMG-T23` | ER-03, ER-10 | 같은 입력·정책·시각 반복; 이후 평가 시각만 만료 이후로 변경 | 반복 결과 동일. 만료 이후 HOLD. 현재 시각 주입 없이 옛 PASS를 영구 재사용하지 않음 |
| `EMG-T24` | ER-08, ER-10 | 원격 API·프로세스 실행·자격증명 접근을 금지한 격리 테스트 하네스에서 전체 사례 실행 | 부작용 시도 0건을 테스트 경계에서 확인. 실제 외부 통제·복구가 구현됐다는 의미가 아님 |

T21/T22의 금지 필드뿐 아니라 허용된 문자열 필드에 들어간 sentinel도 출력 허용목록/오류 처리로 누출되지 않는지 별도 변형으로 확인한다. 단순 정적 문자열 검색과 실행 중 부작용 검사를 구분하고, mock이 잡지 못하는 우회 경로는 남은 한계로 기록한다.

## 후속 단계에서만 검증할 것

P0는 입력에 대한 모의 판정이다. 실제 리소스가 오래된 writer를 거부하는지, 승인 취소가 진행 중 실행에 반영되는지, 데이터 복원이 정상 입력을 보존하는지, 배포 alias/권한 노출이 실제로 사라졌는지는 증명하지 않는다. 이들은 P1/P2에서 대상·접근·실행 범위가 승인된 뒤 별도 비프로덕션 시험으로 검증한다. P0 fixture 통과를 라이브 안전성 증거로 재사용하지 않는다.

## 실제 결과 기록 양식

아래 칸은 구현 담당이 실제 실행한 뒤 작성한다. 기본 상태는 미실행이다.

| 시나리오 ID | subject SHA / 정책 revision | 환경·실행 명령 | 실제 결과 | 증거 참조·한계 |
|---|---|---|---|---|
| <EMG-Txx> | <정확한 값> | <실제로 실행한 명령> | NOT_RUN / PASS / FAIL / SKIP | <민감정보 없는 참조> |

실제 결과는 구현 PR 또는 기존 증거 저장 규격에 남기고 이 명세 표를 PASS로 바꾸지 않는다. 미실행·생략·독립 검토 미수행은 그대로 공개한다.
