Startup Management ERP · Spec v0.1

Runway ERP 표준 규격10–80인 스타트업용 경영관리 ERP

대표 + 경영지원 1–2명이 영업·재무·인사·결재를 한 화면에서 굴리는 것을 목표로 한 실제 적용 규격. 한국 세무·노무 실무(전자세금계산서, 4대보험, 원천세) 기준.

입력 1회견적→계약→청구 자동 승계
결재 3클릭모바일에서 승인 완결
월마감 D+3매월 3영업일 내 결산

A모듈 구성 P1 = MVP 6주 · P2 = +6주 · P3 = 확장

경영 대시보드P1
  • 현금·번레이트·런웨이
  • MRR/매출, 미수금 에이징
  • 내 할 일(결재·마감)
영업 · CRMP1
  • 거래처·담당자·딜 파이프라인
  • 견적서 → 계약 전환
  • 구독/정기청구 스케줄
매출 · 청구P1
  • 청구서, 전자세금계산서 발행
  • 입금 자동매칭(계좌 연동)
  • 미수 독촉 알림톡
비용 · 매입P1
  • 법인카드 자동수집 + 영수증
  • 경비정산, 매입 세금계산서
  • SaaS 구독·고정비 관리
전자결재P1
  • 품의·지출결의·휴가 양식
  • 금액별 결재선 자동 지정
  • 전결 규정 · 대결
회계 · 결산P2
  • 거래 → 자동분개(계정 규칙)
  • 부가세·원천세 신고 자료
  • 세무사 export(더존 호환)
인사 · 근태P2
  • 입·퇴사, 근로계약, 조직도
  • 출퇴근·휴가·연차 자동계산
  • 스톡옵션 부여 대장
급여P2
  • 급여 계산, 4대보험·소득세
  • 명세서 발송, 이체 파일
  • 퇴직금 추계
프로젝트 · 자산P3
  • 프로젝트별 공수·원가·손익
  • 비품·장비 대장, 감가상각
  • 투자·IR 지표 리포트
