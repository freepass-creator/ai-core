# L2 — Global UI/UX Standard

## Mission
Turn the current UI/UX inventory into a globally usable interaction standard that any product can adopt without losing its own brand.

## Extend, do not replace
- `docs/UI_UX_INVENTORY.md`
- `design-system/tokens.css`
- `design-system/components.css`
- UI tests and browser evidence
- product-specific learning files

## Standardize
- design tokens and semantic tokens
- typography scale and density
- spacing/grid/layout breakpoints
- headers, list/detail, bottom actions and navigation hierarchy
- form controls and validation
- loading/empty/error/success/read-only states
- overlays, confirmations and destructive actions
- touch, keyboard, focus and accessibility
- responsive mobile/tablet/desktop behavior
- locale-aware text expansion
- date/time/timezone
- number, decimal, grouping, currency and units
- address/name/phone input variance
- LTR/RTL tolerance
- file/image upload behavior
- offline/draft/retry/recovery interaction
- visual and interaction regression rules

## Product-owned
Brand color, density choice within allowed ranges, icon family, tone, domain labels and domain-specific priority actions.

## Required artifacts
- normative standard document
- token/component contract
- pattern catalog
- accessibility/i18n checklist
- consumer conformance tests
- exception registry

## Definition of done
At least two materially different consumer products can implement the same behavior contract and pass the same conformance checks without copying each other's branding.
