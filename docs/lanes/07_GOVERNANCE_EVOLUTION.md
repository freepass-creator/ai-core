- semantic versioning policy for contracts
- compatibility window
- ADR/decision record
- exception registry
- adoption matrix
- deprecation and migration
- ownership/codeowners concept
- documentation hierarchy
- canonical vs evidence/history labeling
- stale-evidence detection
- standard promotion gates
- periodic audit rules
- naming/glossary governance

## Definition of done
A future contributor can determine which standard is current, who owns it, which consumers use it, what exceptions exist and how to replace it without silently breaking older consumers.
