# AI Core Adoption v0.1

## 지금 하지 않는 것
AIOPS CONTROL_PLANE/ROLES/AI_GUIDE, DevCenter AGENTS/inspection policy/SSOT 정의, 기존 프로젝트, 운영 데이터·배포·권한을 변경하지 않는다. Gmail 기록을 현재 정본으로 자동 승격하지 않는다.

## 단계
0. **Incubator** — 현재. 설계 후보만 보존.
1. **Read-only Pilot** — 실제 작업 3종 이상에서 패킷을 읽기 전용 생성.
2. **Shadow Comparison** — 기존 작업과 Core 계획을 비교.
3. **Limited Adoption** — 검증된 한 영역에서만 시작 표준으로 채택. 실행 권한은 기존 제어면 유지.
4. **Expand or Reject** — 실제 결과가 나아진 영역만 확대.

## 측정 후보
- 사용자가 다시 설명한 횟수
- 잘못된 정본 선택
- 기존 자산을 놓친 재개발
- 수정 후 재검증 누락
- 근거 없는 완료 주장
- 재작업 횟수

## 채택 조건
기존 안전 경계를 약화시키지 않고, 정본 중복이 없고, 현재 revision 검증이 가능하며, HOLD/실패를 숨기지 않고, 최소 한 실제 업무 지표가 개선돼야 한다.
