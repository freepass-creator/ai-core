# AI Core Evolution v0.1

발전 단위는 버전 번호가 아니라 **새로 제거한 실패 모드**다.

각 후보는 답해야 한다.
1. 이전에는 어떤 실제 오류를 놓쳤는가?
2. 새 방식은 그 오류를 어떻게 발견/예방하는가?
3. 정상 작업을 얼마나 방해하는가?
4. 합성 테스트 외 어떤 독립/실무 검증이 필요한가?
5. 어느 범위에서만 유효한가?
6. 실패하면 어떻게 되돌리는가?

학습 루프: `Prediction → Action → Evidence → Outcome → Error Analysis → Candidate → Independent/Pilot Validation → Adopt/Reject`

다음은 단독 발전 증거가 아니다: 문서 길이, 테스트 개수, AI 다수 동의, 새 이름/버전, 해시 일치, 성공 응답 하나.

학습 대상:
- 업무 사실·운영 실패·업무 절차 → AIOPS 후보
- 개발 규격·검사기·재사용 부품 → DevCenter 후보
- 라우팅·컨텍스트·능력 선택·학습 메커니즘 → AI Core 후보

Core는 대상 저장소를 자동 수정하지 않는다. 후보와 증거를 만든 뒤 해당 소유 시스템의 검토/승인 규칙을 따른다.
