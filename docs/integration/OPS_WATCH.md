# AI Core 가 운영 회차를 지켜본다 — 2026-09-18

대표(2026-09-18, 카톡 원격 세션 경유): 「freepasserp5 상품 SSOT 갱신을 이제 코어 고도화가 담당한다 —
시트와 ERP 에 정보가 제대로·끊김 없이 가게」 → 이 대화에서 「감시부터 시작해」.

```
npm run ops:watch -- --env-file C:\dev\freepasserp.com\.env.local
```

`registry/operations.json` 에 적힌 운영마다 두 가지를 **따로** 본다.

| | 무엇을 읽나 | 왜 따로인가 |
|---|---|---|
| 회차 건강 | GitHub 워크플로 회차(`gh api` GET) | 예약이 왔나 · 끝났나 · 실패했나 |
| 자료 나이 | Firestore `ops/public_catalog_publication` **문서 한 건** GET | 회차가 「실패」여도 자료는 들어갔을 수 있다 |

상태: `OK` · `OFF_HOURS`(창 밖 — 조용) · `LATE`(와야 할 예약이 안 옴) · `STALE_PUBLICATION`(창 안인데 발행이 허용나이보다 묵음) · `FAILED`(마지막으로 끝난 회차 실패 — 자료가 들어갔는지 같이 찍는다) · `UNKNOWN`(못 읽음 — 괜찮다고 하지 않는다).
알릴 것이 있으면 exit 1. 결과는 `.local/ops-watch.json`.

**지켜보기만 한다.** 켜지도, 다시 걸지도, 쓰지도 않는다. 열쇠 값은 찍지 않는다.
