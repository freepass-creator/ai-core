## 호출법 — 유지보수 참조이며 실행하지 않음

승인된 단일 파일을 대상으로 하는 형식은 다음과 같다. 사용자가 명령어를 작성해야 한다는 요구가 아니라 담당 AI가 이어받을 참조다.

```text
python C:/dev/aiops/scripts/전사.py "<승인된 오디오 파일 경로>" --language ko
```

인자 없이 실행하면 카카오톡/Downloads 전체를 걷어오므로 이 조사에서 실행하지 않았다. 실제 전사·모델 다운로드·GPU 사용·외부 전송·파일 이동을 수행하지 않았다.

`C:/dev/freepass-sales/교차추출.py`와 기존 `C:/dev/sales/교차추출.py`는 **전사 후 텍스트에서 AI별로 항목을 뽑아 대조하는 별도 도구**다. 앞부분 설명과 호출 코드는 텍스트 비식별 후 외부 AI CLI 사용을 명시한다. 로컬 ASR과 동일한 처리 주체라고 설명하면 안 된다. 해당 도구도 실행하지 않았다.

## 실제 가동 여부와 입력 확인 경계

- 지정된 프로젝트 코드 범위에서 scripts/전사.py 호출자를 검색했다. sales 교차추출은 참조 설명이었으며 다운로드 완료 자동 호출 연결은 찾지 못했다. 다른 프로젝트/미등록 도구의 부재까지 입증한 것은 아니다.
- Windows 예약 작업 action과 프로세스에서 정확한 전사.py/faster_whisper 관련 패턴만 조회했을 때 일치 항목은 0이었다. 현재 해당 명령이 실행 중이라는 증거가 없으며, 다른 이름의 wrapper·수동 과거 실행까지 부정하지 않는다.
- 사용자 지정 카카오톡 폴더의 실제 입력 확인은 별도 비공개 조회로 진행했다. 이 Git 문서에는 개인 파일명·전사문·원음·개인별 pairing을 기록하지 않는다. 해당 입력의 확인 여부를 기능 코드의 완성도나 가동 증거로 대신하지 않는다.
