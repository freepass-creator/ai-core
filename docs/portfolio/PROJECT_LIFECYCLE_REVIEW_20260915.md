### 향후 삭제 검토의 구체 조건 — 실행 계획 아님

삭제검토 등록은 현재 **0건**이다. 위 어느 경로라도 향후 제안하려면 다음 칸을 실제 값으로 채운 별도 검토안이 필요하다.

1. **대상 고정:** 정확 절대 경로·Git common-dir·포함/제외 파일 목록, 연관 worktree/브랜치·원격을 확인한다. 프로젝트 전체와 캐시를 한 번에 묶지 않는다.
2. **보관본:** 사용자가 선택한 비공개 저장 위치에 Git 이력/refs와 dirty·미추적·필요한 ignored 원본을 보존한다. 현재 보관 위치·보관본은 미정/미생성이다. 비밀·고객 원문은 Git 보고서로 복사하지 않고 접근제한·암호화 방식을 별도로 정한다.
3. **무결성:** 보관 manifest와 각 원본/사본 SHA-256 및 전체 묶음 해시를 대조한다. 현재 해시 산출·백업은 수행하지 않았다. `.git` bundle만으로 미추적/브라우저/운영 데이터를 복구할 수 없다.
4. **복원 검증:** 격리된 임시 경로에 복원하고 파일 수·해시·필수 진입점 및 합성자료로 필요한 기능을 검증한다. 운영 연결/외부 쓰기 없이 복원 가능성을 입증한다.
5. **의존성:** 실제 서비스 배포, 연결 도메인, 작업 스케줄, ERP·앱 링크, 공유 라이브러리, 작업 트리 소유자 및 외부 소비자를 확인한다. 본 조사는 문서 관계까지만 확인했다.
6. **보존·승인:** 법무·회계·계약·창작 원본의 보존기간과 사용자 결정을 확정한다. 현재 기간은 미정이며 추정하지 않는다. 구체 대상·보관본·복원 검증 결과를 보고 사용자 직전 승인을 받는다. 자동 삭제 날짜·일괄 삭제는 만들지 않는다.

## 조사 한계와 인계

- README·인계·Git 메타데이터·앱 목록만으로 조사했다. 테스트, 배포, 서비스 응답, 실제 DB, 메일/고객 원문, 법무 원본 내용, 예약 작업 실행 상태를 조회하지 않았다. **모든 프로젝트의 배포 실상태는 미확인**이다.
- 서로 다른 시점의 개별 읽기다. 조사 후 작업 중인 저장소의 commit·dirty 수는 바뀔 수 있다. 원격 URL 설정은 확인했지만 대부분 원격 최신 HEAD·archive 설정은 조회하지 않았다.
- 전체 업무·지시 이력 조사 작업 ID는 초기 앱 목록에서 보이지 않았다. 미생성/실패로 단정하지 않으며 `docs/context/`를 읽거나 수정하지 않았다. 이 보고서는 프로젝트 생애주기만 다룬다.
- 독립 논리검토를 Claude Code에 비민감 요약·도구 비활성으로 요청했으나 주간 한도로 실행 불가였다. 독립 OK나 다중 AI 합의로 표현하지 않는다. 분류는 총괄·사용자 검토 전 제안이다.
- 후속 담당은 각 프로젝트의 기존 작업이다. 포트폴리오 조사가 코드 수정·이관·삭제를 대신 실행하지 않는다.
