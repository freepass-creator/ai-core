키트 지문 — 호출 자리까지 닫는 구조안

PR #356 세 번째 지적(호출 자리·인자·결과 합성이 지문 밖, compat_version 안 올려도 통과)에 대해 함수별 지문을 계속 늘리는 대신 구조로 닫으려 한다. 반례만: (1) bootstrap 을 둘로 — session-bootstrap.mjs(안전 핵심: 신선도·권한·검증·차단)와 .ai-core/advisory.mjs(경고 기능: 가지 흐름 등). bootstrap 은 advisory 를 동적 import 해 그 결과 중 «문자열 경고 배열»만 warnings 에 붙인다(차단·상태는 못 바꾼다, 실패하면 ADVISORY_UNAVAILABLE 경고). (2) 지문 = 고정 fixture 로 키트를 실제 생성해 session-bootstrap.mjs 전문 + verify-kit.mjs + kit.json 의 blocking_inputs/advisory_inputs/freshness_inputs/compat_version 을 해시. 그러면 설치 쪽 호출 자리와 bootstrap 의 모든 배선이 들어가고 advisory.mjs 만 빠진다. (3) 버전 강제: 테스트가 git show origin/main:registry/academy-kit-compat.json 을 읽어, 지문이 main 과 다르면 compat_version 이 main 보다 커야 통과(origin/main 을 못 읽으면 건너뛰지 말고 실패하게? 아니면 경고?). (4) advisory_inputs 는 advisory.mjs 를 만드는 코드 위치로 한정. 동의/수정 짧게.
