## 검토 상태와 다음 행동

현재 상태는 `LOCAL_TESTED_REVIEW_PARTIAL`이다. 새 원장 스키마에 대한 보수적인 품질 게이트에서는 추가 보조 AI 검토가 필요하다. Cursor의 설계·구현·후속 재검토는 완료했지만, Claude 재시도는 주간 한도, Gemini 재시도는 작업 폴더 신뢰 설정에서 막혔다. 이를 통과로 계산하지 않았고 신뢰 설정을 우회하지 않았다.

실제 오더 `ORD-31638d3e-3253-4d04-a6d3-77fdace544ea`는 `REVIEW`로 남아 있으며 추가 검토 HOLD를 메모에 기록했다. 사용자 최종 확인은 하지 않았다. 오더의 REVIEW는 결과 기록 접수를 뜻하며 필수 검토 완료를 의미하지 않는다.

다음 작업자는 `node scripts/orders.mjs show ORD-31638d3e-3253-4d04-a6d3-77fdace544ea`로 현재 상태를 읽고, 추가 검토 가능 여부부터 확인한다. 그 뒤 작은 실제 오더로 공통 인계를 사용해보고 도구별 읽기 전용 자동 연결을 확장한다.

## 실행 범위

`npm run orders:serve` → `http://127.0.0.1:4318`. 서버는 로컬 루프백에만 바인딩된다. `.local/` 데이터와 수집 미러는 Git에 포함하지 않는다. 로그인·서명 검증·원격 접속·예약 실행·자동 발송·운영 배포·여러 PC 동기화는 구현 범위 밖이다.
